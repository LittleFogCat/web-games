## 1. 目标

修复“从建造栏选中防御塔后，详情提示窗盖住战场最下方两行，导致无法在底部网格建造”的问题；不改变建造、升级、回收与数值。

## 2. 范围

- 选中建造卡片或已建设施时，详情面板接管建造栏所在的底部条带：与建造栏同宽、同高、同底，不向战场网格延伸。
- 详情面板高度由建造栏实际高度驱动（`--intel-h`），保证 320×568 / 390×667 / 390×844 下都不覆盖第 15、16 行网格。
- 取消、部署成功、点击空白处后恢复 9 栏建造栏。
- 版本号 `0.14.4-dev` 同步到 `index.html`、`styles.css?v=`、`src/*.js?v=`、`README`、`AGENTS`、`dist/`。
- 重新生成 `screenshots/home.png`（页脚版本）、`release/vector-td-v0.14.4-dev-static.zip` 与 `.sha256`。
- 更新 `docs/deployment.md` 线上记录；部署并验证 `BUILD 0.14.4-dev`。
- 回归：9 种建造卡片 + 设施详情在三档视口与建造栏同高同底、底行可建造、无横向溢出、控制台无错误；检查 UTF-8 无 `U+FFFD`。

## 3. 不包含

- 矢量反应、超载、新模式、新地图、新塔、天赋、光环、升阶、融合。

## 4. 验收标准

- 详情面板底边与建造栏底边重合，高度等于建造栏高度，顶边不高于战场网格底边（overlap = 0）。
- 320×568 / 390×667 / 390×844 下均可在第 15、16 行（含核心两侧）点击建造。
- 取消 / 部署 / 点击空白处后建造栏 9 个栏位恢复；设施详情的升级 / 回收仍可用。
- 无横向溢出；控制台无错误；无 `U+FFFD`。
- `BUILD 0.14.4-dev` 在本地与线上一致；`dist/` 与 release 包一致；部署前备份、staging 校验、部署后公网验证完成。
