# Baseline 0.14.5-dev — 平衡性调整

> 状态：in_progress  
> 基线版本：0.14.5-dev  
> 依赖：0.14.4-dev（已验收、已部署）  
> 计划周期：1–2 周  
> 最后更新：2026-10-31

## 1. 目标

基于 0.14.4 基线做一轮**数据驱动的平衡调整**；不新增机制、模式、塔或地图。

## 2. 范围

- **【用户指示，已纳入范围】调试面板一键重置进度**：清零金币、全局技能、星区解锁与星级记录，便于快速回到开荒状态验收；不改动正常玩法，同步 CLI `reset` 与控制台 `__VECTOR.debug.resetProgress()`。
- **【用户指示，已纳入范围】三档玩家验收工作流**：建立 `tools/balance-gate.js`，把骨灰（不刷金币/不修复/无伤）、普通（懂克制/适度刷）、无脑（平铺棱镜/满技能）做成可执行矩阵；验收标准改为三档契约，旧“满技能 L10 允许 0–40% 损失”作废。
- 用 `vector-td/tools/sim-headless.js` 跑单档诊断：`ace / normal / full` 技能档，L1–L10，`prism / mixed` 策略。
- 识别四类问题：
  1. 统治策略（单塔/单流派能否平推）；
  2. 关卡尖刺（哪几波、哪几关异常难/易）；
  3. 塔/技能的投入产出比（DPS/晶元、升级阶梯）；
  4. 经济盈余/缺口（晶元过多导致无取舍，或过少导致无解）。
- 只改 `src/config.js` 的数值/曲线：塔伤害/费用/射程/冷却、敌人抗性/生命、波次成长、经济参数；系统规则改动（纳米修复）单独登记。
- 每次只改一个维度；至少跑 L4 / L7 / L9 / L10 四个采样关。
- 同步单位图鉴、游戏策划文档、README 的相关表格。
- 版本 `0.14.5-dev`、`BUILD`、`?v=`、`dist`、`release`、部署与线上验证。

## 3. 候选调整轴（按数据决定，不预设结论）

- **【用户指示，已纳入范围】三档契约**：骨灰无伤、普通全通、无脑无法完成战役；旧档位表只作历史参考。
- **【本轮已落地】纳米修复只奖励干净波次**：本波有漏怪不触发，封死“漏怪换输出、修复回血”的躺赢打法。
- **【本轮已落地】铁壁动能抗性 65% → 75%**：让纯动能/纯棱镜在 L7–L10 真正被物抗墙淘汰，混编激光仍是答案。
- **【本轮已落地】L9/L10 开局与中段减压**：W1 移除隐匿、W3 降低铁壁/相位数量，避免三裂口开局即无解；终波与 Boss 保持。
- **【历史轴】控制机制重做**：移除"霸体"，新增"韧性"；震荡塔击退；已在 0.14.5 前几轮落地。
- 棱镜 / 机炮的投入产出与 IV 级齐射曲线。
- 动能 / 能量对护盾的剪刀差（×0.45 / ×1.9）与物免/魔免分布。
- 灯塔的 60 + 125 晶元投入是否值得一个塔位。
- `WAVE_HP_GROWTH`、`lateWaveHp`、`lateWaveSpeed` 与中盘压力。
- 升级阶梯（`UPGRADE_COST_MULTIPLIERS`）与技能经济（金币收入/技能成本）。
- 只选 2–3 个轴，不一次全改。

## 4. 验收标准

- **骨灰级**：L1–L10 全部通关且核心从未掉血（不刷金币、不点修复）；允许存在 bot 追不上的手工解，但需手测记录。
- **普通级**：L1–L10 全部通关（允许掉血/漏怪，L10 1 星即可）；首通 + 1–2 轮适度刷金币。
- **无脑级**：只铺棱镜 + 必要灯塔、满技能，**无法完成战役**（L4 起至少一关失败；L10 必须失败）。
- 不存在“单塔/单流派平推全战役”的统治策略；至少 3 种可通关 build。
- 十关总有效 HP 与总收入相对 0.14.4 变动有明确理由；除非有意，控制在 ±10%。
- 3 星曲线不被抹平；手机三尺寸、60fps、控制台无错误。
- 旧存档可迁移；构建 / 发布 / 部署 / 线上 BUILD 验证通过；无 `U+FFFD`。

## 5. 工作顺序

1. 跑 0.14.4 基线模拟，保存“调整前”矩阵。
2. 从数据里选 1 个最明确的异常，提出 1 个最小改动。
3. 只改这个变量，重跑 L4/L7/L9/L10 + 全战役。
4. 对比调整前后：通关率、完整度、HP/收入、塔伤害占比。
5. 通过后手测 3 局；再进入下一个轴。
6. 全部通过后更新文档、版本、构建、部署；在基线文档与日志标记 `accepted`。
