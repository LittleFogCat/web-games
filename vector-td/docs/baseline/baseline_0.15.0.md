# Baseline 0.15.0 — 战斗层：等离子 + 超载

> 状态：planned  
> 基线版本：0.15.0  
> 依赖：0.14.3-dev（补丁线收尾）  
> 计划周期：2–3 周  
> 最后更新：2026-10-29

## 1. 目标

在经典模式加入**矢量反应（首版等离子）**与**超载**，验证“按下去爽不爽”；不新增模式。

## 2. 范围

### 2.1 矢量反应

- 攻击给敌人挂 3 秒伤害类型印记；两种不同印记触发反应；同敌人 1.5 秒内置 CD，Boss 3 秒。
- 首版只做**等离子**（动能 + 能量）：范围爆炸、削盾、3 秒破甲；伤害占比目标 20–30%。
- 敌人印记 UI（三角 / 方块 / 雪花）；反应飘字 0.6 秒；独立 VFX / SFX。
- 同类型不反应；单类型 build 仍可通关。

### 2.2 超载

- 击杀和伤害给“超载能量”充能；经典模式 80 杀充满。
- HUD 建造栏右上方 56px 圆形按钮；`R` 快捷键；手机拇指可达。
- 触发后 6 秒：敌人移速降至 30%，塔射速 ×2、伤害 +20%。
- 每击杀延长 0.1 秒，上限 +3 秒；结束后 20 秒冷却，过热 4 秒（射速 -20%）。
- 经典模式 L3 解锁；L1–L2 不出现。

### 2.3 经典模式接入

- 不改 10 关地图与波次数据；不改金币、星级、技能结算；不改存档主结构。
- 反应 / 超载在经典关 L3 后生效。

### 2.4 UI / 文档

- 320×568 下按钮、印记、飘字可读；暂停/建造/超载不冲突。
- 同步单位图鉴、游戏策划文档、README、AGENTS、部署文档。

## 3. 不包含

- 超导、碎冰、新地图、新敌人、新模式、模块、天赋、光环、升阶、融合。

## 4. 验收标准

- L1 / L3 / L5 各 3 局：玩家能主动触发超载，并说出“什么时候想按”。
- 等离子可读，伤害占比 20–30%；单类型 build 仍能过 L1–L3。
- 原有 3 星、金币、技能、暂停/续战、建造/升级/回收无回归。
- 320×568 / 390×667 / 390×844 无横向溢出；中端机 60fps；控制台无错误。
- 旧存档可迁移；`BUILD`、`dist`、release、部署校验通过；无 `U+FFFD`。

- [ ] 文档：单位图鉴、游戏策划文档、README、AGENTS。

## 6. 风险

- 反应绕过特性克制 → 反应不无视魔免/霸体；伤害占比设上限。
- 超载过强/过弱 → 充能、时长、冷却三项一起调，不单改一个。
- 手机按钮误触 → 56px 热区、与建造栏留 8px 间距。
- 性能 → 粒子上限、同屏敌人上限 200。
