# Baseline 0.16.0 — 超载模式

> 状态：planned  
> 基线版本：0.16.0  
> 依赖：0.15.0 accepted  
> 计划周期：3 周  
> 最后更新：2026-10-29

## 1. 目标

新增短局街机模式：快充能、连续超载、刷分；单局 8–10 分钟。

## 2. 范围

- 1 张紧凑地图，10–12 波，8–10 分钟。
- 超载充能快（30 杀）、持续 8 秒；超载期间击杀得分 ×2。
- 每 3 波自动充满一次，鼓励连续超载。
- 补齐**超导**（能量 + 低温）与**碎冰**（动能 + 低温）；三种反应全部可用。
- 分数、连击、结算、本地最佳记录；无永久成长。
- 模式入口、模式 HUD、结算页；不新增常驻资源条。
- 与经典模式隔离存档；不写金币/星级。

## 3. 不包含

- 无限模式、模块三选一、每日/每周、天赋、光环、升阶、融合。

## 4. 验收标准

- 单局 8–10 分钟；至少 3 种可通关 build；分数有重复挑战价值。
- 三种反应都能在实战中被识别；没有单一反应统治。
- 经典模式无回归；模式间存档不污染。
- 同屏敌人上限 200；60fps；320×568 无溢出。
- 构建 / 发布 / 部署 / 线上 BUILD 验证通过。
