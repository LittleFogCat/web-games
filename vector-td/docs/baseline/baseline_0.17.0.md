# Baseline 0.17.0 — 无限模式

> 状态：planned  
> 基线版本：0.17.0  
> 依赖：0.16.0 accepted  
> 计划周期：3–4 周  
> 最后更新：2026-10-29

## 1. 目标

新增长局 build 模式：无尽潮汐、每 5 波巨潮、每 3 波三选一模块；单局 15–25 分钟。

## 2. 范围

- 无尽波次生成器：5 秒整备，敌人密度/生命逐波上升。
- 每 5 波巨潮：数量 ×3、预警 3 秒、屏幕边缘脉冲。
- 每 3 波三选一模块；首版 8–12 张，目标 20 张；模块改变行为，不做纯数值。
- 死亡结算：最佳波次、最佳分数、击杀。
- 残片/解锁只做横向，不加永久伤害。
- 与经典/超载模式隔离存档。
- 320×568 三张竖排模块卡。

## 3. 不包含

- 新地图/群系、每日/每周、天赋、光环、升阶、融合。

## 4. 验收标准

- 单局 15–25 分钟；70% 玩家能到第 10 波；至少 3 种模块 build。
- 没有单一模块选取率 >75%；没有“必选模块”。
- 同屏敌人上限 200；60fps；手机可读。
- 失败页能说明“死在第几波、漏了什么伤害类型”。
- 构建 / 发布 / 部署通过。
