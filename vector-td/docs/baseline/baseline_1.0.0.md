# Baseline 1.0.0 — 正式版内容

> 状态：planned  
> 基线版本：1.0.0  
> 依赖：0.17.0 accepted  
> 计划周期：4–6 周  
> 最后更新：2026-10-29

## 1. 目标

把游戏做成可正式发布的 1.0：补经典战役内容、打磨新手/性能/发布质量；**不新增战斗系统**。

## 2. 范围

- 经典战役扩展：建议 2–3 个新星区 / 地图，每关 16–20 波。
- 1 个新首领或首领变体；2–3 个新敌人组合（优先复用现有机制）。
- 新手引导、难度曲线、3 星评价、金币/技能经济复核。
- 性能与可访问性：低端机降特效、色盲友好、320×568。
- 全量回归：L1–L10、经典/超载/无限三模式、暂停/续战、建造/升级/回收、存档迁移。
- 发布物料：截图、README、单位图鉴、策划文档、发布包、部署验证。

## 3. 不包含

- 元素地图、光环、天赋预设、升阶、融合；这些放 1.1–2.0。

## 4. 验收标准

- 战役总时长增加 30–50%，但不靠重复波次填充。
- 无技能 L1–L3 通过；满技能 L10 有压力但不无伤碾压。
- 三种模式都能正常进入；无模式间存档污染。
- 手机三尺寸无溢出；60fps；控制台无错误。
- 构建 / 发布 / 部署 / 回滚全部演练通过。
