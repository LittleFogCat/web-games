# Baseline 1.1.0 — 元素星域

> 状态：planned  
> 基线版本：1.1.0  
> 依赖：1.0.0 accepted  
> 计划周期：4–6 周  
> 最后更新：2026-10-29

## 1. 目标

让地图成为“第三个反应参与者”：熔岩 / 冰雪 / 电浆三群系与环境连锁。

## 2. 范围

- 3 个群系：熔火星核、永冻星带、电浆云海；每群系 2 张图，共 6 图。
- 环境印记：敌人站元素格获得印记；与塔的印记按现有三反应触发。
- 环境连锁：反应在元素格上向相邻同群系格传播，60% 效果、最多 3 格、每格 4 秒 CD。
- 每图 1 个环境事件（喷发 / 冰震 / 磁暴），提前 2 秒预警。
- 每群系 2 个新单位 + 1 个首领；环境伤害占比 ≤25%。
- 元素地图接入经典/无限/超载；Canvas 程序化绘制地形。

## 3. 不包含

- 光环、天赋预设、升阶、融合。

## 4. 验收标准

- 每个群系至少 2 种通关 build；没有“只有一种元素能打”的硬锁。
- 环境伤害 ≤25%；320×568 可读；60fps。
- 新地图不破坏现有 10 关平衡。
- 构建 / 发布 / 部署通过。
