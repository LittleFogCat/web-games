# Baseline 1.2.0 — 光环 + 天赋预设（方向验证）

> 状态：planned  
> 基线版本：1.2.0  
> 依赖：1.1.0 accepted  
> 计划周期：3–4 周  
> 最后更新：2026-10-29

## 1. 目标

验证两条远期方向，不追求完整内容：

- V 级光环：让摆位多一层支持关系；
- 局外天赋预设：开局前配好，局内只执行，不打断战斗。

## 2. 范围

### 2.1 光环

- 4 个 V 级光环：灯塔照明、冻结寒霜、电弧导电、重炮引力井。
- 同类型不叠加，取最强；半径 2.0–2.5 格；地面细环。
- 不新增常驻 UI；选中塔显示范围。

### 2.2 天赋预设（只做方向验证）

- 只做 1–2 座塔（建议棱镜）的“III 选路线、V 选进阶”原型。
- 3 个预设槽；局外配置；战役每关前 / 超载 / 无限 run 前可换。
- 局内不出现天赋面板；塔详情只读。
- 不做完整七塔天赋树；具体路线、数值、解锁方式留到后续基线。

## 3. 不包含

- 完整 28 个天赋、升阶、融合、新地图。

## 4. 验收标准

- 光环塔选取率 >30%；没有单一光环最优。
- 预设流程可用：玩家能在开局前完成配置，局内不再改。
- 至少两种不同打法；没有一条路线全面更强。
- 320×568 可读；无模式回归；构建 / 部署通过。
