# Baseline 1.3.0 — 升阶

> 状态：planned  
> 基线版本：1.3.0  
> 依赖：1.2.0 accepted  
> 计划周期：2–3 周  
> 最后更新：2026-10-29

## 1. 目标

给 V 级塔一条具名升阶路线，让“纵向强化”与“横向融合”形成选择。

## 2. 范围

- 7 条具名升阶路线（棱镜→灵能弩塔、机炮→风暴机炮、重炮→奇点炮、激光→熔穿光束、震荡→共振场、冻结→永冻核心、电弧→万钧雷暴）。
- V 级 + 星核 + 晶元；每座塔只能升阶一次。
- 升阶改变行为，不只是数值；同一伤害类型不变。
- 升阶与 V 级天赋互斥；具体边界在基线启动时定。
- 星核获取、升阶 UI、塔详情显示升阶形态。

## 3. 不包含

- 融合、远征、新地图。

## 4. 验收标准

- 升阶使用率 >50%；没有单一升阶统治。
- 升阶与天赋边界清晰，不出现双重叠加。
- 三种反应、超载、光环联动无回归。
- 手机可读；60fps；构建 / 部署通过。
