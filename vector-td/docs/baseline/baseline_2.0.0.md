# Baseline 2.0.0 — 融合 + 远征

> 状态：planned  
> 基线版本：2.0.0  
> 依赖：1.3.0 accepted  
> 计划周期：6–8 周  
> 最后更新：2026-10-29

## 1. 目标

把塔的“横向组合”做成终局系统，并用 3 章结构化远征把所有系统整合起来。

## 2. 范围

- 6 个融合配方（电弧+冻结=超导脉冲塔、棱镜+激光=等离子长矛、重炮+震荡=引力震荡塔、机炮+灯塔=相位哨戒塔、冻结+重炮=碎冰迫击炮、激光+电弧=电弧激光）。
- 两座相邻 V 塔 + 融合核心；消耗两座塔，占 2 个塔位。
- 融合塔固定 profile，不继承天赋；可回收 50%；组合外形 / 独立攻击。
- 3 章结构化远征：编队 / 威胁 / 模块 / 路线 / 残片，整合反应、超载、光环、天赋、升阶。
- 远征结算、记录、解锁；不污染经典模式。
- 全系统平衡与性能测试；发布物料。

## 3. 不包含

- 新群系 / 新地图（已由 1.1 覆盖）；第 4 种反应（视情况另立基线）。

## 4. 验收标准

- 单局远征 20–30 分钟；无单一融合 / 天赋统治。
- 融合占 2 塔位但强度合理（约 1.6–1.8 座 V 塔），玩家愿意用。
- 经典 / 超载 / 无限 / 远征都能正常进入；手机 60fps；无溢出。
- 完整发布 / 部署 / 回滚。
