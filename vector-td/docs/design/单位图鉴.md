## 0. 阅读说明

- 本图鉴覆盖 **7 座攻击塔 + 灯塔 + 1 种壁垒 + 11 种敌人**。
- 表中的生命、速度、奖励、伤害均为 `vector-td/src/config.js` 中的**基础值**；实战数值会乘关卡系数、波次成长与全局技能。
- 防御塔的“累计投入”= 建造 + 升到该等级的全部升级费用（含 `1.0 / 1.3 / 2.0 / 3.2` 阶梯系数）。
- DPS = 单体基础输出；棱镜的多目标、重炮的溅射、震荡 / 冻结的范围、电弧的链式总伤害会另行列明。
- “首次出现”指该单位第一次进入波次编排的星区；同一星区内可能重复出现。
- 伤害类型：**动能 KINETIC**、**能量 ENERGY**、**低温 CRYO**。
- 抗性写作“−X%”表示伤害减免 X%，“+X%”表示受到该类型伤害增加 X%（易伤）。

## 1. 伤害类型与特性速查

### 1.1 伤害类型

| 类型 | 防御塔 | 对护盾 | 对生命 | 设计定位 |
| --- | --- | ---: | --- | --- |
| 动能 KINETIC | 棱镜、机炮、重炮 | ×0.45 | 正常（受物免影响） | 实体弹道；破盾差，但能穿透魔免力场 |
| 能量 ENERGY | 激光、震荡、电弧 | ×1.90 | 正常（受能抗 / 魔免影响） | 高能光束；破盾快，但被魔免 / 能抗削弱 |
| 低温 CRYO | 冻结 | ×0.90 | 正常（受魔免影响） | 直接伤害低，主要提供减速 |

护盾结算顺序：

1. 先按伤害类型倍率计算护盾伤害；
2. 扣护盾；
3. 护盾被击穿后，溢出部分按倍率折算回生命值；
4. 生命值伤害再乘抗性系数。

### 1.2 特性

| 特性 | 关键词 | 效果 | 克制 |
| --- | --- | --- | --- |
| 护盾 | SHIELD | 独立护盾条；能量 ×1.9、动能 ×0.45、低温 ×0.9 | 激光 / 电弧 / 震荡 |
| 物免 | ARMOR | 动能伤害按单位减免（重棱 40%、铁壁 75%） | 能量 / 低温 |
| 魔免 | WARD | 能量与低温伤害减免 75% | 棱镜 / 机炮 / 重炮 |
| 能抗 | ENERGY RESIST | 能量伤害降低 40% | 动能 / 低温 |
| 能量易伤 | FRAGILE | 受到的能量伤害 +20% | 激光 / 电弧 / 震荡 |
| 韧性 | TENACITY | 按类型独立减免减速与击退（铁壁 80%、终焉 100%）；被控会累积对应韧性至 80% | 纯伤害塔；控制收益极低 |
| 隐匿 | STEALTH | 常规索敌无法锁定；仅灯塔范围内可被命中 | 灯塔 |
| 分裂 | SPLIT | 死亡时分裂为两个高速残片 | 重炮 / 震荡 / 电弧 |
| 终焉 | BOSS | 最终首领；护盾 + 韧性 100% | 动能破甲 + 能量破盾 |

**控制与韧性细则：**

- 减速与击退分两条轨道独立结算；控制命中会累积对应轨道韧性：+12%/次，上限 80%（终焉 100%）。
- 实际控制效果 = 原始效果 ×（1 - 对应韧性）。铁壁初始 80%：54% 减速只剩 10.8%，0.35 格击退只剩 0.07 格。
- 震荡塔附带击退：0.1 秒快速位移，最大 0.6 格；0.9 秒免疫窗，核心周围 1.6 格为击退免疫区。
- 韧性只削减控制，不免疫伤害；高韧性单位仍然吃满伤害。

### 2.2 棱镜箭塔 PRISM

使用建议：前中期性价比最高的铺场塔；后期若敌群以魔免为主，可保留 2–3 座。对隐匿目标需要灯塔先行揭示，破盾能力仍然很差。

### 2.5 相干激光 LASER

### 2.6 谐振震荡塔 SHOCK

- **定位**：近域范围脉冲 + 击退；不依赖锁定，但只命中已由灯塔揭示的敌人。
- **伤害类型**：能量。
- **特性**：以自身为圆心的范围伤害 + 击退（0.1s 快速位移，最大 0.6 格）；不再提供减速。
- **核心克制**：护盾、物免、密集敌群、核心前拦截。
- **被克制**：魔免（×0.25）、高韧性（击退大幅削减）、远程压制（射程极短）、隐匿（需要灯塔揭示）。

### 2.7 熵减冻结塔 FROST

- **伤害类型**：低温。

- **核心克制**：高速游隼、残片、密集敌群。
- **被克制**：韧性（减速与击退大幅削减，且反复被控会累积韧性）、魔免（×0.25）、隐匿（无法锁定）。

使用建议：后期伤害占比很低，但减速能显著提高其他塔的有效输出。面对高韧性波时收益有限；面对高速 / 分裂波时优先级很高。

### 2.9 灯塔 BEACON

- **定位**：侦测支援单位；不攻击，只负责揭示隐匿。
- **建造费用**：60 晶元。
- **侦测半径**：3.5 格；升阶后 4.5 格。
- **占位**：1 格，占用 1 个防御塔位（12 座上限内）。
- **升级**：可升阶一次——花费 125 晶元升为「远侦灯塔」，侦测半径 3.5 → 4.5。
- **核心作用**：半径内的隐匿单位会被揭示，所有防御塔都能锁定并攻击它们；离开半径会重新隐匿。

| 属性 | 数值 |
| --- | --- |
| 建造费用 | 60 晶元 |
| 侦测半径 | 3.5 格（升阶后 4.5 格） |

## 4. 调试与生成

调试模式下可直接在局内生成测试敌群：

```js
__VECTOR.debug.spawn('aegis', 5);      // 生成 5 个折光盾卫
__VECTOR.debug.spawn('wraith', 3);     // 生成 3 个幽影
__VECTOR.debug.spawn('boss', 1);       // 生成 1 个首领
__VECTOR.debug.addCrystals(500);       // 加晶元
__VECTOR.debug.godMode(true);          // 无敌核心
__VECTOR.debug.freeBuild(true);        // 免费建造 / 升级
__VECTOR.debug.maxTowers();            // 所有塔升到 V 级
__VECTOR.debug.win();                  // 直接胜利
```

可用类型 ID：

```text
scout, drone, brute, splitter, shard, warden,
aegis, wraith, juggernaut, nullifier, boss
```

生成单位使用当前波次的 HP 系数；准备阶段生成会自动进入交战。调试战斗不写入正式进度。

## 5. 平衡备注

1. **护盾与物免是两种不同的“硬”**：护盾怕能量，物免怕能量；魔免怕动能。玩家需要同时准备动能与能量，而不是只换一座塔。
2. **韧性不免疫伤害**：它只按比例削弱减速与击退。不要因为“控制收益低”就放弃震荡的伤害与拦截。
3. **隐匿不是完全隐形**：它阻止索敌与伤害；只有灯塔范围揭示后才能被任意攻击塔命中。UI 必须让玩家看到“单位在，但需要灯塔”。
4. **能量易伤是正反馈**：重棱的物免让动能吃亏，能量易伤让能量占便宜，形成明确的“换塔”教学。
5. **灯塔是唯一的反隐手段**：它不攻击、占用 1 个塔位（可花费 125 晶元升阶扩大半径），因此建造位置比数量更重要；多裂口地图需要覆盖主要航线。
6. **冻结的伤害很低**，它的价值在减速；如果玩家只看出装 DPS，会低估它。图鉴与设施详情需要明确标注“控制”而不是“输出”。
