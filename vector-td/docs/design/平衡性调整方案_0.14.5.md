## 0. 摘要

当前体感问题不是“最终波不够难”，而是：

> **大部分关卡的大部分波次过于简单，甚至无聊；最终波难度恰好或稍高；Boss 血量放在最后一关是合理的。难度跳跃来自前面太低，而不是后面太高。**

因此本轮调整的方向是：

1. **抬高压力地板，不抬天花板**：前中期增加紧张感；终波与 Boss 保持现状。
2. **用密度/组合/时机制造压力，不用加血制造血牛**。
3. **不做成魂游**：正常首通、不重复刷金币/技能的玩家，应能通过 L10；允许 1–2 次漏怪/重开，但不要求帧级操作。
4. **首通预算可通关**：目标是用 3–4 条关键技能线通过 L10，而不是刷满 4,580 金币的七条线。
5. **去掉重复强化波**：追加波必须提供新组合/新压力，而不是同一组再刷一遍。

## 1. 背景与反馈

### 1.1 玩家体感

- 多数关卡的前中期波次压力过低，清屏后长时间空等。
- 最终波难度“恰到好处或稍高”，Boss 血量作为最后一关的难点合理。
- 难度跳跃主要来自“前面太松”，不是“后面太陡”。
- 不希望变成魂游或折磨人的游戏；正常推进、不重复刷技能点，应能通关。

### 1.2 静态数据旁证

- L1 W1：游隼 ×10、gap 0.8s，出生 8 秒、路径约 18 秒；2 座 I 级棱镜约 41 DPS，总 HP 158，理论 4 秒清完。
- L3 无技能无头模拟：16 波全部 0 漏怪、100% 完整度（bot 偏强，仅作旁证）。
- 多关存在完全相同的连续波次：L1 W8=W9=W10；L2 W10=W9、W12=W11；L3–L9 也有类似重复。
- 首通十关金币约 2,100，满星额外约 300，合计约 2,400；七条技能线总成本 4,580，首通预算只能覆盖约 52%。

### 1.3 结论

这不是“数值全面偏低”，而是**压力分布错误**：

- 总 HP/收入不一定低，但出生密度、同屏压力、决策频率太低；
- 难度被堆到最后 1–2 波，前中期缺少“差点漏怪”的紧张时刻；
- 技能经济可能逼迫重复刷，和“正常通关”目标冲突。

## 2. 目标与非目标

### 2.1 目标

- 每关前中期至少有 **1–2 个“需要做决策/差点漏怪”的波次**。
- 不允许连续 3 波“零压力、零决策、纯清屏”。
- 首次通关、不重复刷金币/技能的玩家，能用 **3–4 条关键技能线**通过 L10。
- 无技能可稳定通过 L1–L3；L4 起开始需要技能/克制，但不能变成“必须刷满”。
- 终波与 Boss 保持当前强度；除非新数据证明，否则不调 Boss 血量。
- 手机端仍可读、可暂停、可建造；不增加操作复杂度。

### 2.2 非目标

- 不做魂游/高惩罚：不要求零漏怪、不要求帧级操作、不取消暂停/整备。
- 不靠“加血”制造难度；不把普通波变成血牛。
- 不新增模式、塔、敌人特性或地图（本轮只调现有内容）。
- 不为了难度而砍经济到“买不起塔”；经济只作为压力调节的次要杠杆。
- 不改终波/Boss 作为主要手段；本轮先修前中期。

## 3. 诊断

### 3.1 “总量”不等于“压力”

当前每关总有效 HP/收入表看起来不低，但体感由三个变量决定：

```text
瞬时压力 ≈ 同时在场敌人数 × 单怪威胁 × 玩家有效 DPS 覆盖率
节奏压力 ≈ 出生间隔 × 波次时长 × 空窗期
决策压力 ≈ 新类型/新特性/分线/资源取舍
```

当前问题主要是：

- **出生间隔太长**：早期 0.8–0.6s，怪一只只来，塔逐个点杀，没有“顶不住”的瞬间。
- **波次空窗太长**：25s 初始 + 12s 波间 + 清屏后的等待，玩家大量时间在看空路。
- **前期单位类型太单一**：前 3 波基本是游隼/棱卫，没有需要换塔的威胁。
- **强化波重复**：追加波没有带来新组合，只是把同一组再刷一遍。
- **难度后置**：`lateWaveHp` 把压力堆到最后 3–5 波，前中期成长太慢。

### 3.2 重复波清单

| 关 | 完全相同的连续波次 |
| ---: | --- |
| L1 | W8=W9=W10；W11=W12 |
| L2 | W10=W9；W12=W11 |
| L3 | W11=W10；W13=W12 |
| L4 | W11=W10；W13=W12 |
| L5 | W12=W11；W14=W13 |
| L6 | W12=W11；W14=W13 |
| L7 | W13=W12 |
| L8 | W13=W12 |
| L9 | W14=W13 |
| L10 | 无 |

**判断：** 这是“波次数变多、内容没变多”的典型症状；它直接稀释了中盘紧张感。

### 3.3 首通经济与技能门槛

| 项目 | 数值 |
| --- | ---: |
| 首通十关金币 | 2,100 |
| 满星额外 | 约 300 |
| 首通合计 | 约 2,400 |
| 七条技能线总成本 | 4,580 |
| 首通覆盖率 | 约 52% |

**判断：** 如果 L10 需要 4–5 条线，正常首通玩家必须重复刷金币；这和“不重复刷也能正常通关”冲突。需要把“首通可通关”作为硬验收。

### 3.4 关卡侧重点

| 关卡 | 当前问题 | 优先级 |
| ---: | --- | --- |
| L1–L3 | 前中期太松、重复波、单位类型单一 | P0 |
| L4 | 第一次护盾；不要加盾卫数量，靠前 2 波密度提升 | P1 |
| L5 | 三裂口 + 隐匿 + 灯塔同时出现，认知负荷高 | P1 |
| L6–L7 | 中盘重复波；L7 经济偏紧，但先不动经济 | P1 |
| L8–L9 | 重复波多；终波保持 | P1 |
| L10 | 终波/Boss 体感合适，不动 | P2（观察） |

### 3.5 数值侧重点

- **不要先动 Boss**：终波和 Boss 是当前少数“体感合适”的部分。
- **不要先加血**：加血会让战斗变磨，不会增加紧张感。
- **优先动 gap / 数量 / 类型组合 / 空窗**。
- **首通预算**是独立验收项，不能靠“玩家多刷几次”解决。

## 4. 设计原则

1. **抬地板，不抬天花板**：前中期更紧，终波/Boss 保持。
2. **压力来自“同时处理不了”**：更多同屏、更多分线、更多需要换通道的单位；不是更多血。
3. **每 3 波至少 1 次决策**：建造、升级、换目标、补灯塔、补破盾，至少发生一个。
4. **允许 1–2 次漏怪**：不要求零漏；失败应可解释，不应“突然必死”。
5. **首通可通关**：正常推进、不重复刷，3–4 条关键技能线能过 L10。
6. **不增加操作复杂度**：不加新按钮、不要求快速点击；暂停/整备仍可用。
7. **先小范围验证，再推广**：先 L1–L3，确认“有压力但不烦”，再动后面。

## 5. 目标压力曲线

| 阶段 | 目标体感 | 允许的失败 | 主要手段 |
| --- | --- | --- | --- |
| W1–3 | 教学，但不能零压力 | 只建 1 座塔应漏 1–2 只 | 缩 gap、+10–15% 数量 |
| W4–7 | 第一次做选择 | 错误塔种/不升级漏 1–2 只 | 精英探头、分线、特性组合 |
| W8–12 | 中盘持续有压力 | 错误 build 漏 2–3 只 | 变体波、双裂口、混合类型 |
| W13–终波 | 高潮 | 保持现状 | 不改终波/Boss |

> “允许失败”是设计预期，不是强制让玩家失败；目标是“差点漏”的紧张感，不是“必然漏”。

## 6. 调整方案

### 6.1 全局节奏

| 杠杆 | 当前 | 建议 | 说明 |
| --- | ---: | ---: | --- |
| 初始部署 | 25s | **20s** | 试运行；暂停仍可长考，不会真赶 |
| 波间整备 | 12s | **10s** | 减少空等；若手机反馈太赶，回退 12s |
| 早期 gap | 0.8–0.6s | **-15–20%** | 优先改这个，而不是加血 |
| 早期数量 | 基准 | **+10–15%** | 只加前 3–5 波，不全局加 |
| 精英探头 | 无 | 每关 W3–W5 加 1 只 | 只加 1 只，不加整波 |
| 重复波 | 存在 | **全部替换为变体** | 换裂口/换类型/加 1 只精英 |
| 波次成长 | 1.035 | 暂不动 | 先改密度；不够再动成长 |
| 终波/Boss | 当前 | **不动** | 体感合适，先不碰 |

**执行顺序：** 先 gap/数量 → 再看是否需要动 `lateWaveHp`；不要同时改多个全局变量。

### 6.2 逐关调整建议

> 以下为**建议值/方向**，不是最终配置；每关先做 1–2 项，复跑后再加。

#### L1 初次接触

- **问题：** W1 10 只游隼 gap 0.8，2 塔清完还有大量空等；W8–W10 三连相同。
- **建议：**
  - W1 游隼 10→12，gap 0.8→0.65；
  - W4 重棱 1→2（只加 1 只，测试新手是否漏）；
  - W8–W10 改为三种不同组合：一架棱卫、一架游隼+棱卫、一架重棱+游隼；
  - 终波不动。
- **护栏：** 无技能仍应通过；若 W4 双重重棱导致新手必漏，回退为 1 只。

#### L2 双生航路

- **问题：** W2 早期尖刺，W9–W12 重复。
- **建议：**
  - W2 棱卫 12→10、游隼 6→8，gap 0.8→0.65；让“分线”而不是“单点厚血”成为压力；
  - W3 裂变体 4→5；
  - W9–W12 改为左右裂口轮换的变体，不要同组重复；
  - 终波不动。

#### L3 棱镜回廊

- **问题：** 能抗首次出现太轻；W11/W13 重复。
- **建议：**
  - W3 相位哨卫 1→2；
  - W4 相位 3→4；
  - W10–W13 改为“相位+分裂/重棱”轮换，不要重复；
  - 终波不动。
- **护栏：** 无技能仍应通过，完整度允许从 100% 降到 85–95%。

#### L4 日冕风暴

- **问题：** 第一次护盾；不要加盾卫数量，避免“高盾+低收入”双重压力。
- **建议：**
  - 前 2 波加 2–3 只游隼/棱卫，提高密度；
  - W3 盾卫保持 3 只，不增加；
  - W10–W13 重复波改为“盾卫+不同杂兵”的变体；
  - 不改经济，先看压力提升后的体感。

#### L5 碎裂星带

- **问题：** 三裂口 + 隐匿 + 灯塔同时出现，认知负荷高。
- **建议：**
  - W1–W2 只从单侧裂口出怪，先教“灯塔覆盖”；
  - W3 起三裂口全开；
  - 不增加幽影数量；重复波改为不同裂口组合；
  - 如果实现成本高，退而求其次：W1–W2 降低幽影数量/延后出现。
- **护栏：** 不增加“必须双灯塔”的硬要求；单灯塔 + 合理位置应能过。

#### L6–L7

- **问题：** 中盘重复波；L7 经济偏紧。
- **建议：**
  - L6 W2 虚空织者 3→4；W11/W13 重复波改组合；
  - L7 W2 铁壁 1→2 或加 1 只重棱；W12/W13 改组合；
  - L7 经济暂不动；如果压力提升后仍紧，再单独调 `rewardScale`。
- **护栏：** L7 不允许变成“必须满技能”；首通预算内应能过。

#### L8–L9

- **问题：** 重复波多，终波保持。
- **建议：**
  - 只替换重复波：换裂口、换精英、加 1 只高价值单位；
  - 不增加终波护卫；终波保持当前强度；
  - L9 三裂口轮换要保证每个裂口都有实际压力，而不是只堆一侧。

#### L10

- **建议：** 本轮不动。
- **理由：** 终波/Boss 体感合适；先修前中期。若前中期压力提升后 L10 显得偏易，再单独评估 Boss，不在本轮一起改。

### 6.3 首通经济方案

当前首通约 2,400，技能总成本 4,580。建议三选一或组合：

| 方案 | 做法 | 影响 |
| --- | --- | --- |
| A. 提高首通金币 | 首通总金币 2,100→2,700–2,900 | 玩家更快成型；需同步重复奖励比例 |
| B. 降低技能总成本 | 4,580→3,200–3,600 | 减少刷；但已点技能的老玩家需要补偿/重置 |
| C. 降低 L10 技能依赖 | L10 目标从 5 条线降到 3–4 条 | 不改经济；需要调 L10 或技能强度 |

**推荐：A + C 组合**：

- 首通金币提高约 25%，让正常玩家能买 3–4 条关键线；
- L10 按 3–4 条线设计，不要求满树；
- 不直接砍技能总成本，避免老玩家资产贬值；如果后续仍偏刷，再考虑 B。

**验收：** 从 0 金币开始，只打首通、不重复，按合理顺序点技能，L10 能过（1 星也算过）。

### 6.4 重复波替换规则

每个重复波至少满足一条：

1. 换裂口：同一组敌人从不同裂口进入；
2. 换类型：保留一个主类型，替换一个副类型；
3. 加精英：在原有杂兵中加 1 只高价值单位；
4. 改 gap：把 0.8 改成 0.55，或反之，制造节奏差；
5. 改组合：从“单一类型”改成“两种类型混编”。

**禁止：** 连续两波使用完全相同的 `type/count/gap` 组合。

## 8. 风险与回滚

| 风险 | 表现 | 对策 |
| --- | --- | --- |
| 早期加密度过头 | 新手 L1–L3 连续失败 | 先只改 L1–L3，逐波复跑；允许回退 gap |
| 首通金币提高导致经济膨胀 | 中后期钱多、无取舍 | 同步降低重复奖励或提高升级成本；优先观察晶元余额 |
| L5 单侧裂口实现复杂 | 需要改刷怪逻辑 | 先做“W1–W2 减少幽影数量/延后出现”的轻量版 |
| 加精英导致尖刺 | 某波必漏 | 一次只加 1 只；用无技能/低技能档复跑 |
| Bot 与人类差异 | 模拟通过但手测无聊 | 以手测体感为准；bot 只做回归，不做唯一结论 |
| 改终波/Boss 的冲动 | 前中期修好后终波显得偏易 | 本轮不动；下一轮单独评估 |

## 9. 实施顺序（建议）

### Phase 0：数据与基线

- 记录当前每关每波的通关时间、漏怪、晶元余额；
- 建立“首通预算”测试档（不是满技能档）；
- 不改配置。

### Phase 1：L1–L3（最小验证包）

- 只改 gap、少量数量、1 只精英探头；
- 替换 L1–L3 重复波；
- 手测 3 局/关，确认“有压力但不烦”。

### Phase 2：L4–L7

- L4 不加盾卫数量，只加前 2 波密度；
- L5 单侧裂口教学；
- L6–L7 加 1 只精英、替换重复波；
- 暂不动 L7 经济。

### Phase 3：L8–L10

- 只替换重复波；
- L10 与 Boss 不动；
- 跑首通预算 run，确认 3–4 条线可过。

## 11. 结论

本轮不是“全面加难”，而是：

> **把前中期从“清屏等待”改成“有压力、有决策、差点漏”；终波和 Boss 保持；首通不刷也能过。**

先做 L1–L3 最小验证包。如果这三关的体感从“无聊”变成“有点紧但能过”，再推广到 L4–L10；如果 L1–L3 变成“必须完美操作”，说明加密度过头，回退 gap/数量，保留重复波替换和首通经济修正。
