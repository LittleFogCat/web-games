## 0. 修订原因

原方案把“L10 终波/Boss 体感合适”错误地扩大成了“L10 整关本轮不动”。

这个结论不成立：

- 终波/Boss 合适，不等于 L10 前 19 波也合适；
- L10 前期同样可能出现“清屏等待、没有决策”的问题；
- 如果只修 L1–L9，L10 前期仍是免检区，压力曲线会在最后一关断掉。

**本修订案只修正这一点：L10 的 W20 + Boss 不动；W1–W19 仍按同一压力标准检查。**

原方案文件保持原样，不直接修改；阅读时以本修订案为准。

## 3. 修订后的 L10 调整原则

1. **先组合，后数量**：优先换精英/换类型/换裂口；最后才加杂兵数量。
2. **先 gap，后 HP**：缩 gap 制造瞬时压力；不加血制造血牛。
3. **一次只改 1–2 波**：不要整关一起加；先 W1–W4，再看 W5–W10。
4. **W20 不动**：终波/Boss 不作为本轮变量。
5. **性能护栏**：同屏单位不超过 200；手机 60fps；不出现软锁。
6. **首通护栏**：3–4 条技能线仍要能过 L10；不允许变成“必须满技能/重复刷”。

## 4. 候选调整（按优先级）

> 以下为候选，不是全部执行；每轮只选 1–2 项，复跑后再决定下一项。

### 4.1 W1–W4：先验证“L10 前期是否真的松”

| 波次 | 候选 | 目的 | 风险 |
| ---: | --- | --- | --- |
| W1 | 幽影 7→8，或游隼 gap 0.22→0.20 | 提高开局隐匿压力 | 新手/低技能档可能直接漏 |
| W2 | 虚空织者 5→6 | 强化“魔免 + 护盾”双通道检查 | 纯能量 build 可能被卡 |
| W3 | 铁壁 4→5 | 强化韧性/物免检查 | 同屏与高有效 HP，谨慎 |
| W4 | 重棱 9→10，或幽影 gap 0.4→0.35 | 提高中段密度 | 可能挤压灯塔覆盖 |

**建议先做 W1 + W2**，因为这两波最能代表 L10 的“开局是否紧张”；W3/W4 等第一轮复跑后再决定。

### 4.2 W5–W10：替换同质波

- W7 的“盾卫 + 虚空”与 W5 类似，可改成“盾卫 + 幽影”或“虚空 + 铁壁”，避免连续同质；
- W10 的“虚空 + 相位”可加入 1 只铁壁，变成三通道检查；
- 不增加 W20 护卫；不复制 W11–W19 的强化波。

### 4.3 W11–W19：只做“去重/换组合”

- 这些波已经是高压段，原则上不加数量；
- 如果发现某波与前一波完全相同或过于相似，只换一个类型/裂口；
- 终波前保留 12 秒整备，不额外加压力。

### 4.4 W20 + Boss：不动

- Boss 血量、护盾、韧性、护卫构成保持；
- 如果前 19 波修好后 W20 显得偏易，另开一轮评估，不在本修订案中处理。

## 5. 验收标准（L10 部分）

- [ ] L10 W1–W19 至少出现 **2 次“差点漏/需要决策”** 的波次；
- [ ] 不允许连续 3 波“0 漏、0 决策、0 压力”；
- [ ] W20 与 Boss 的体感、完整度损失与当前版本接近；
- [ ] 首通预算 3–4 条技能线可通过 L10（1 星即可）；
- [ ] 同屏单位 ≤200；手机三尺寸 60fps；无软锁；
- [ ] 不出现“必须满技能/重复刷金币”的硬门槛。

## 7. 实施顺序

### Phase 3a：L10 W1–W4

- 只改 W1/W2 各一个变量；
- 复跑首通预算档与 3–4 条线档；
- 记录 W1–W4 清场时间、漏怪、同屏峰值。

### Phase 3b：L10 W5–W10

- 只替换同质波/加 1 只精英；
- 不改 W20。

### Phase 3c：L10 W11–W19

- 只去重/换组合；
- 不增加终波压力。

### Phase 3d：确认 W20/Boss

- 如果前期改动后 W20 仍合适，结束；
- 如果 W20 偏易/偏难，另开修订案，不在本轮改。
