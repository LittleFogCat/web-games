## 0. 摘要

**现状不是“内容太短”，而是“通关后没有下一局”。**

10 个星区、170 波、约 2,968 个单位、约 1 小时首通。玩家在前 1 小时已经见完 7 座塔、11 个单位定义、9 种特性；之后再怎么加关卡、加波数，都只是把同一套题再做一遍。

**本报告给出的方向不是“加难度”，而是“加爽感”：**

| 层 | 机制 | 作用 |
| --- | --- | --- |
| 压力 | **无限模式（潮汐）** | 无尽尸潮、每 5 波巨潮，制造密度与紧张 |
| 成长 | **模块三选一** | 每 3 波变强，形成“这局我的 build” |
| 释放 | **超载** | 一个按钮，子弹时间 + 全屏反应风暴 |
| 组合 | **矢量反应** | 动能/能量/低温两两反应，靠建造而不是操作 |

**模式不是替代关系，而是并列：** 经典模式负责长线推进，超载模式负责短局爆发，无限模式负责长局 build；三者共享同一套战斗层。

**远期（1.1–2.0）：** 元素星域地图（熔岩 / 冰雪 / 电浆）、V 级光环、局外天赋预设、塔的升阶与融合；详见第 12 章。

**手机适配原则：只加一个按钮、一个三选一浮层；反应与特效全部发生在战场内，不新增常驻面板。**

**版本线：** 开发阶段版本号重置为 **0.x**。旧线 `1.13.1` 归档为历史构建；当前基线为 **0.14.3-dev**（0.14.x 补丁线），下一验收版本为 **0.15.0**，路线为 0.15 → 0.16 → 0.17 → 1.0。

## 1. 背景与判断

### 1.1 现状盘点

| 维度 | 数值 |
| --- | ---: |
| 星区 | 10 |
| 波次 | 170（每关 14–20） |
| 敌人单位总数 | 2,968 |
| 战役累计有效 HP | 约 580,000 |
| 战役晶元总收入 | 约 21,000 |
| 防御单位 | 7 攻击塔 + 灯塔 + 壁垒 |
| 敌人定义 | 11（9 常规 + 残片 + 首领） |
| 敌人特性 | 9 |
| 全局技能 | 7 条 × 5 阶 = 35 阶，4,580 金币 |
| 首通时长 | 约 60 分钟（1×，含重试） |

### 1.2 为什么“加关卡 / 加波数”无效

1. **信息边际趋零。** 新关卡只能提供“地图形状”和“血量系数”，塔、敌人、特性、克制关系都是旧的。
2. **1.13 已经做过一次时间膨胀。** 波次 8–14 扩到 14–20、人口 ×1.45，再用生命 ×0.62 / 奖励 ×0.64 补偿；单关变长，决策密度不变。
3. **一次性内容的成本/消耗比很差。** 一张 9×16 地图 + 20 波编排，玩家 8 分钟消耗完。
4. **纯数值 meta 会加速寿命结束。** 技能满阶后关卡更简单，玩家失去挑战，也失去继续刷的理由。

### 1.3 从“耐玩”到“爽感”

此前 [游戏扩容策划书](游戏扩容策划书.md) 的重心是“Roguelite 结构 + 难度协议”，解决的是**复玩性**；但玩家真正想要的是**力量幻想**：

> 不是“这关更难”，而是“我变强了、我清屏了、这是我搭出来的”。

**流程拉长和爽感并不冲突：** 经典模式继续承担长线推进与内容消耗；超载 / 无限模式承担高频释放。两者共享战斗层，是并列的产品线，不是替代关系。

### 1.4 三个参考，各取什么

| 参考 | 真正要取的 | 不取 | VECTOR 的落点 |
| --- | --- | --- | --- |
| PvZ 无尽 | 无尽波次、巨潮预警、击杀产出资源 | 草坪网格、植物卡收集 | 潮汐波次、巨潮、晶元 |
| 亿万僵尸 | 尸潮密度、破口紧张、墙 + 塔堵口 | 慢速基地建造、PC 高 APM | 9×16 墙/塔、核心防线 |
| 吸血鬼幸存者 | 三选一成长、组合进化、满屏弹幕 | 移动/躲避、经验条 | 模块三选一、反应连锁、超载清屏 |

手机端额外的“取”与“不取”：

- 取：一个拇指可达的触发键、全屏暂停的三选一、战场内的视觉反馈。
- 不取：多资源条、技能栏、背包、拖拽瞄准、横向滚动页签。

## 2. 爽感模型

### 2.1 核心循环：压力 → 成长 → 释放

```text
潮汐上涨（敌人密度 ↑）
        ↓
击杀产出晶元 / 充能
        ↓
每 3 波：三选一模块（变强）
        ↓
每 5 波：巨潮（压力峰值）
        ↓
攒满 → 超载（清屏释放）
        ↓
更猛的潮汐
```

### 2.2 四个爽感来源

| 来源 | 表现 | 对应机制 |
| --- | --- | --- |
| **密度** | 屏幕被敌人填满，塔群同时开火 | 无限模式（潮汐）/ 超载模式 |
| **成长** | 每几分钟多一个改变打法的模块 | 三选一 |
| **爆发** | 一键进入子弹时间，全屏蒸发 | 超载 |
| **组合** | 三系塔打出不同反应，连锁清场 | 矢量反应 |

### 2.3 五条设计原则

1. **爽感优先于难度。** 难度是张力，释放才是产品；先保证“按下去很爽”，再调“撑到按下去很难”。
2. **反应靠建造，不靠操作。** 玩家摆塔、选位、形成组合；不需要切人、连招、瞄准。
3. **输入随机 > 输出随机。** 地图、波次、三选一是输入随机；暴击、闪避、随机索敌是输出随机，不用于胜负。
4. **每个机制都要能被手机拇指完成。** 一个按钮、一个浮层、战场内可视化。
5. **爽感不能绕过克制。** 反应是混编的奖励，不是无视特性的通行证。

### 2.4 难度和爽感的关系

- 无限 / 超载模式让压力持续上升，但玩家的成长速度要更快；
- 超载是“保底释放”：即使 build 不完美，攒满也能清一波；
- 真正的难度来自“什么时候按、按给哪一波”，而不是“敌人血更厚”。

## 3. 模式架构：经典 / 超载 / 无限

> **流程拉长和爽感不是二选一。** 经典模式负责“长线推进”，超载/无限模式负责“高频释放”；三者共享同一套塔、敌人、反应和超载。

### 3.1 一张表看懂

| 模式 | 结构 | 单次时长 | 超载充能 | 成长 | 结算 | 定位 |
| --- | --- | ---: | ---: | --- | --- | --- |
| **经典** | 10 星区 / 14–20 波 | 5–8 分钟/关 | 慢（80 杀） | 金币 + 技能 + 星级 | 星级 / 进度 | 主线、教学、长线 |
| **超载** | 1 图 / 10–12 波 | 8–10 分钟 | 快（30 杀） | 少量局内模块 | 分数 / 连击 | 街机式爽感 |
| **无限** | 无尽波次 | 15–25 分钟 | 中（60 杀） | 每 3 波三选一 | 最佳波次 / 分数 | 长局 build / 记录 |
| **远征（后续）** | 3 章 / 30 波 | 20–30 分钟 | 中 | 模块 + 编队 | 深度 / 残片 | 结构化 Roguelite |

### 3.2 共享层

三种模式共享：

- 塔、敌人、地图、建造 / 升级 / 回收；
- 矢量反应（第 4 章）；
- 超载（第 5 章）；
- 暂停、倍速、续战、移动端 HUD。

区别只在“容器”：

- 波次怎么来；
- 玩家怎么变强；
- 失败 / 胜利怎么结算；
- 一局多长。

这样开发成本是叠加的，不是三套游戏。

### 3.3 经典模式

- 现有 10 星区、14–20 波、3 星、金币、7×5 技能全部保留。
- 新增：矢量反应 + 超载；超载在 L3 解锁；反应首版只做等离子，后续再加超导 / 碎冰，保持教学节奏。
- 超载充能慢（80 杀），定位是“战术大招”，不是每波都放。
- 不解锁模块；保持战役的纯粹和可读。
- 目标：让老玩家重打经典关时，有新的打法（反应组合 + 超载时机）。

### 3.4 超载模式

- 1 张紧凑地图，10–12 波，8–10 分钟。
- 超载充能快（30 杀），持续 8 秒；超载期间击杀得分 ×2。
- 每 3 波自动充满一次，鼓励连续超载；怪物密度高、波次短。
- 目标：分数、连击、记录；不做永久成长。
- 定位：随时来一局的“街机模式”，也是超载机制的教学场。
- 解锁：通关 L3。

### 3.5 无限模式（潮汐）

- 无尽波次，5 秒整备；每 3 波三选一模块，每 5 波巨潮。
- 超载充能中等（60 杀）；死亡结算；记录最佳波次 / 分数。
- 定位：长局 build 成长、记录挑战；用模块把反应和超载 build 起来。
- 解锁：通关 L5（首版建议 L5，让玩家早点体验）。

#### 3.5.1 波次结构

| 阶段 | 时长 | 内容 |
| --- | ---: | --- |
| 整备 | 5 秒 | 建造、升级、回收；可点“立即发兵” |
| 交战 | 20–30 秒 | 敌人从 1–2 个裂口涌入 |
| 巨潮 | 每 5 波 | 数量 ×3，预警 3 秒，屏幕边缘脉冲 |
| 结算 | 核心归零 | 波次、击杀、分数、最佳记录 |

- 没有章节、没有终点；死亡即结算。
- 波次间隔比战役短，节奏更快；但保留暂停建造，长考仍然可行。
- 巨潮后给一次稀有模块三选一，作为“撑过去”的奖励。

#### 3.5.2 难度曲线（首版）

| 波次 | 敌人数/波 | 生命倍率 | 目标 DPS | 体验 |
| ---: | ---: | ---: | ---: | --- |
| 1 | 10 | 1.00 | 120 | 建立基础火力 |
| 5 | 18 | 1.35 | 250 | 第一次巨潮 |
| 10 | 28 | 1.90 | 450 | build 成型 |
| 15 | 38 | 2.70 | 700 | 反应开始连锁 |
| 20 | 50 | 3.80 | 1,000 | 满屏压力 |
| 30+ | 65+ | 7.00+ | 1,500+ | 记录挑战 |

- 数量每波 +12%，生命每波 +7%；巨潮额外 ×3 数量。
- 难度增长要略慢于玩家成长；打不过时优先“再多活 2 波”，而不是“必须换 build”。

#### 3.5.3 经济

- 击杀晶元自动入账，不做掉落拾取；手机上不需要额外操作。
- 开局 220 晶元；击杀奖励随波次成长；巨潮额外 +60。
- 支出：建造、升级、回收；塔位上限仍为 12。
- 目标：第 10 波能维持 8–10 座塔，第 20 波有 2–3 座 V 级。

#### 3.5.4 三选一模块

- 每 3 波暂停，三选一；巨潮后额外一次。
- 无限模式首版 8 张，之后扩到 12–20 张；同名最多 2 层。
- 模块分三类：
  - **塔的质变**：棱镜 +1 弹射、冻结击杀爆炸、重炮范围 +30%；
  - **反应强化**：等离子范围 +25%、超导链 +1、碎冰对冻结目标 +30%；
  - **经济/防线**：击杀回充能 +50%、塔位 +1（核心上限 -20）、回收 100%。

> 模块不是“+10% 伤害”；每张都要能改变玩家下一步的建塔决策。

#### 3.5.5 结算与记录

```text
score = 波次 × 100 + 击杀 × 2 + 巨潮存活 × 300
```

- 记录：最佳波次、最佳分数、最佳击杀。
- 元资源：潮汐残片，只解锁模块 / 编队 / 称号，不加永久伤害。
- 失败页要写出“死在第几波、主要漏了什么伤害类型”，方便下一局调整。

### 3.6 解锁与进度

- **经典**：金币、技能、星级；主线。
- **超载**：分数、称号；不写金币，避免刷分影响战役经济。
- **无限**：残片、模块、记录；不写金币。
- **远征（后续）**：残片 / 编队；作为 1.0 之后的结构化变体。
- 三种模式互不污染存档；切换模式不丢当前局（沿用现有续战规则）。

### 3.7 为什么这样不冲突

- 经典模式解决“我想推进 / 看内容”；
- 超载模式解决“我现在就想爽一把”；
- 无限模式解决“我想用一套 build 打很久”。
- 三者共享战斗层，所以不会把开发资源撕成三份；每加一个模式，主要是加“容器”和结算。
- **流程拉长靠经典（以及后续新星区），爽感靠超载 / 无限；两者是并列的产品线，不是替代关系。**

## 4. 核心机制：矢量反应

### 4.1 三条通道，正好三种反应

游戏已有动能 / 能量 / 低温三条伤害通道。不要新增元素；三系两两组合，正好三种反应，手机上能记住。

| 组合 | 反应 | 效果 | 视觉 |
| --- | --- | --- | --- |
| 动能 + 能量 | **等离子** | 范围爆炸，削盾 50%，附加 3 秒破甲（受伤 +15%） | 紫白爆裂 |
| 能量 + 低温 | **超导** | 链式传导 3 个目标，减速 30%，降低能量抗性 | 蓝白链电 |
| 动能 + 低温 | **碎冰** | 对冻结/减速目标额外 15% 最大生命伤害，碎片溅射 | 冰晶炸裂 |

### 4.2 印记与触发

- 每次攻击给敌人挂一个 3 秒的“伤害类型印记”。
- 敌人身上出现第二种不同印记时，触发反应，消耗两种印记。
- 同一敌人 1.5 秒内最多触发一次；Boss 3 秒，防止无限连锁。
- 同类型不反应；单类型 build 仍有原有克制与射程优势。
- 三种印记同时存在时，取最后施加的两种触发，第三种保留。

### 4.3 为什么是“建造反应”，不是“操作反应”

| 原神式操作反应 | VECTOR 建造反应 |
| --- | --- |
| 切角色、放技能、卡时机 | 摆塔、选位置、形成覆盖 |
| 需要多个技能键 | 不需要新按键 |
| 反应靠手速 | 反应靠布局 |
| 适合 PC/手柄 | 适合手机单指 |

玩家不是“打反应”，而是“建一个会打反应的防线”。

### 4.4 建造含义

- 激光 + 重炮放在同一条路上 → 等离子；
- 电弧 + 冻结放在拐角 → 超导；
- 棱镜 + 冻结放在核心前 → 碎冰。
- 12 塔位意味着最多 3 组反应对；玩家必须选择“这局走哪两种反应”。
- 反应不要求塔相邻；只要求攻击覆盖同一段路径。这样不会让摆位变得过于苛刻。

### 4.5 与现有克制的关系

- 等离子削盾，但不能无视魔免；
- 超导控场，但对霸体无效；
- 碎冰需要先冻结/减速，不能凭空爆发；
- 反应是“混编的奖励”，不是“混编的门票”；单类型 build 仍可通关，只是少一条爆发路线。

### 4.6 视觉与音效

- 印记：敌人血条上方两个小图标（三角 / 方块 / 雪花），颜色 + 形状双重编码。
- 反应：独立颜色、独立音效、短飘字（0.6 秒）；不堆长文本。
- 连锁：超导最多 3 跳，碎冰最多 3 个溅射目标；防止满屏数字。
- 色盲友好：形状优先于颜色；反应名称用图标角标，不只靠颜色。

## 5. 核心释放：超载

### 5.1 充能与触发

- 击杀和伤害给“超载能量”充能；不同模式充能速度不同（经典 80 杀 / 超载 30 杀 / 无限 60 杀）。
- 充满后，建造栏右上方一个 56px 圆形按钮亮起；点击或按 `R` 触发。
- 手机端按钮在拇指可达区；不在顶部 HUD，避免够不到。

### 5.2 效果

- 持续 6 秒；每击杀 1 个敌人延长 0.1 秒，上限 +3 秒。
- 敌人移速降至 30%（子弹时间）。
- 所有塔射速 ×2、伤害 +20%。
- **反应风暴**：超载期间，所有攻击额外挂上一种与自身不同的印记，强制触发大量反应。
- 画面：降饱和、霓虹描边、震屏、低频音效、击杀数字放大。
- 结束：15 秒冷却；链路/塔群过热，射速 -20% 持续 4 秒。

### 5.3 为什么爽

- **蓄力可见**：充能环、脉冲、音效渐强，玩家知道“快来了”。
- **释放可控**：留给巨潮还是 Boss，是玩家的决策。
- **清屏可读**：子弹时间 + 反应风暴，一眼看懂“我赢了这一波”。
- **build 兑现**：反应是玩家自己搭的，超载只是点火。

### 5.4 数值骨架

| 项目 | 经典 | 超载 | 无限 |
| --- | ---: | ---: | ---: |
| 充能需求 | 80 击杀 | 30 击杀 | 60 击杀 |
| 基础时长 | 6 秒 | 8 秒 | 6 秒 |

## 7. 0.14 MVP：经典模式 + 反应 + 超载

### 7.1 首版做什么

- **不新增模式入口**，先把矢量反应与超载加进现有经典模式。
- 1 种反应：**等离子**（动能 + 能量）。
- 1 个超载按钮：慢充能（80 杀）、6 秒、20 秒冷却。
- 只改战斗层与 HUD；不改关卡数据、不改存档结构（新增字段用默认值）。
- 目标：验证“老关卡 + 新机制”是否立刻变爽，而不是先造一个新模式。

### 7.2 验收标准

- 在 L1 / L3 / L5 各跑 3 局；玩家能主动触发超载，并说出“什么时候想按”；
- 等离子触发可读，伤害占比 20–30%，不能变成唯一解；
- 不破坏原有 3 星、金币、技能与关卡节奏；
- 320×568 下超载按钮可点、印记可读；
- 控制台无错误；中端机 60fps。

### 7.3 测试重点

- 超载触发 / 冷却 / 过热；
- 等离子触发频率与伤害占比；
- 单类型 build 仍可通关；
- 暂停、建造、升级、回收与超载按钮不冲突；
- 旧存档迁移（新增字段默认值）；
- 经典关卡 14–20 波的节奏是否被超载打乱。

### 7.4 工作量

| 工作流 | 估算 |
| --- | ---: |
| 等离子反应 / 印记 | 3 人天 |
| 超载 / 子弹时间 | 2 人天 |
| 经典模式接入 / HUD 按钮 | 2 人天 |
| 平衡与 9 局测试 | 3 人天 |
| 文档 / 回归 | 2 人天 |
| **合计** | **约 12 人天** |

单人全职约 2–3 周；兼职 3–5 周。先验证爽感，不追求新内容量。

## 9. 风险与红线

| 风险 | 表现 | 缓解 |
| --- | --- | --- |
| 反应绕过克制 | 等离子秒一切，特性失效 | 反应不无视魔免/霸体；伤害占比控制在 20–30% |
| 单类型 build 失效 | 不混编就过不了 | 单类型保留原有优势；反应是奖励不是门票 |
| 满屏不可读 | 印记/飘字/特效堆叠 | 只做 3 种反应；飘字 0.6 秒；连锁上限 3 |
| 性能下降 | 尸潮 + 反应 + 子弹时间 | 敌人上限 200；粒子上限；低端机降特效 |
| 超载太强 | 每波都能清屏 | 充能需求、冷却、过热惩罚；Boss 抗性 |
| 复杂度前置 | 新手看不懂 | 首局只给等离子；超载 L3 解锁；渐进提示 |
| 变成“必须混编” | 所有 build 趋同 | 单类型通关成就；反应模块不强制 |
| 手机误触 | 按钮太靠近建造栏 | 56px 热区；与建造栏留 8px 间距；二次确认关闭 |

**红线：**

- 不做“多按钮技能栏”；
- 不做“纯数值 +10%”模块；
- 不做“永久 +伤害”元成长；
- 不做“没有反制的随机词条”；
- 不做“必须每天上线”的日常。

## 12. 远期计划：元素星域 / 光环 / 天赋 / 升阶融合

> 0.14–1.0 先把“反应 + 超载”做深；以下内容放 1.x–2.0，避免首版复杂度和美术成本失控。

### 12.1 元素星域（1.1）

**目标：** 让地图成为“第三个反应参与者”，而不是背景板。

| 群系 | 环境印记 | 地形效果 | 与三系的反应 | 新单位 / 首领 |
| --- | --- | --- | --- | --- |
| **熔火星核** | 灼热（视为能量） | 熔岩格持续灼烧；每 12 秒喷发一次 | 动能=熔渣破甲；能量=过载爆炸；低温=蒸汽爆炸 + 击退 | 熔核兽、火蜥、熔岩首领 |
| **永冻星带** | 冰霜（视为低温） | 冰面减速；每 15 秒冰震冻结 | 动能=碎冰风暴；能量=超导链；低温=深冻 | 霜噬者、冰晶蛛、永冻首领 |
| **电浆云海** | 电浆（视为能量） | 电浆格传导链电；每 18 秒磁暴跳跃 | 动能=等离子；能量=链式过载；低温=超导脉冲 | 电浆游鱼、磁暴无人机、电浆首领 |

**连锁规则：**

- 敌人站在元素格上时获得环境印记；它与塔的印记按现有三反应触发。
- 反应发生在元素格上时，向相邻同群系元素格传播，效果 60%，最多 3 格；每格 4 秒冷却。
- 元素格只影响敌人与反应，不直接伤害塔；环境伤害占比 ≤25%。
- 每张图至少保留 2 条可行伤害通道；不能出现“只有一种元素能打”的硬锁。

**地图与视觉：**

- 每群系 2 张图，沿用 9×16；元素格用低亮度地面纹理 + 边界脉冲，不遮挡路径。
- 每图 1 个环境事件（喷发 / 冰震 / 磁暴），提前 2 秒预警，可被玩家利用。
- 不新增外部美术：熔岩裂纹、冰晶、等离子弧都用 Canvas 程序化绘制。

**为什么放 1.1：** 需要新地图、新敌人、新首领；0.x 先验证反应/超载，不值得一开始就铺三套群系。

### 12.2 光环系统（1.2）

**目标：** 让“摆位”多一层支持关系，而不是只堆 DPS。

**规则：**

- 只有特定塔在 V 级解锁光环；每座塔最多 1 个光环。
- 同类型光环不叠加，取最强；不同光环可共存。
- 光环半径 2.0–2.5 格；地面显示细环，选中塔时显示范围。
- 光环只影响塔/敌人，不新增资源条。

| 塔 | 光环 | 效果 | 定位 |
| --- | --- | --- | --- |
| 灯塔 | 照明 | 范围内友军射程 +5% | 支援 |
| 冻结 | 寒霜领域 | 范围内敌人移速 -10% | 控场 |
| 电弧 | 导电领域 | 范围内能量塔链跳 +15% | 能量 build |
| 重炮 | 引力井 | 范围内敌人被轻微拉向弹着点 | 聚怪 |

**手机 UI：** 选中塔详情里显示“光环”一行；地面细环；不新增常驻图标。
**平衡：** 光环强度 8–15%；不叠加；V 级才有，保证升级有回报。

### 12.3 天赋预设（1.2，远期构想）

- 不做 Dota 2 式局内天赋树，而是**开局前的配装 / 天赋预设**：先配好，局内只执行，不打断战斗。
- 每座塔按“路线 + 进阶”展开：III 级选路线，V 级选该路线的进阶；路线决定后续选项。
- 示例（棱镜）：III 级在“单体（+伤害）”与“多目标（+1 副目标，低伤害）”中选；V 级单体路线可选“致命一击 / 蓄力射击”，多目标路线可选“散射 / 穿透”。
- 预设存在局外：战役每关前、超载 / 无限 run 前可换；局内不出现天赋面板。
- 与现有系统的边界：1.2 起以天赋预设替代 V 级专精；升阶与天赋预设互斥；融合塔不继承天赋。
- 具体路线数量、数值、UI 与解锁方式留到 1.2 立项时再定；棱镜基础多目标重做仍待定。

### 12.4 升阶与融合（1.3–2.0）

**升阶（Ascension）**

- V 级塔 + 星核 + 晶元 → 升阶为具名形态；每座塔只能升阶一次。
- 升阶改变行为，不只是数值；同一伤害类型不变。
- 升阶与天赋预设互斥；具体边界在 1.3 立项时确定，局内不再改。
- 升阶后不能再融合：这是“纵向强化 vs 横向组合”的选择。

| 塔 | 升阶形态 | 行为变化 |
| --- | --- | --- |
| 棱镜 | 灵能弩塔 | 弹道穿透 2 个目标，射程 +0.4 |
| 机炮 | 风暴机炮 | 持续开火射速最高 +50%，射程 -10% |
| 重炮 | 奇点炮 | 炮弹落点前牵引敌人 0.5 格 |
| 激光 | 熔穿光束 | 光束穿透 2 个目标，破盾 +20% |
| 震荡 | 共振场 | 脉冲留下 2 秒伤害场 |
| 冻结 | 永冻核心 | 光环减速 +20%，冻结时间 +30% |
| 电弧 | 万钧雷暴 | 链 +2，15% 眩晕 |

**融合（Fusion）**

- 两座相邻 V 级塔 + 融合核心 + 晶元 → 合体为一座融合塔；消耗两座塔，占 2 个塔位。
- 融合塔有组合外形与独立攻击；不能再次融合/升阶；可回收，返还 50%。
- 融合塔不继承天赋，使用固定 profile，避免“天赋 + 融合”双重叠加。
- 融合塔强度约 1.6–1.8 座 V 塔，不是 2 倍；每配方有明确克制。

| 配方 | 融合塔 | 机制 |
| --- | --- | --- |
| 电弧 + 冻结 | 超导脉冲塔 | 链电 + 减速，每次命中触发超导 |
| 棱镜 + 激光 | 等离子长矛 | 穿透光束，动能 + 能量双通道 |
| 重炮 + 震荡 | 引力震荡塔 | 聚怪 + 脉冲 AoE |
| 机炮 + 灯塔 | 相位哨戒塔 | 高速射击 + 反隐 |
| 冻结 + 重炮 | 碎冰迫击炮 | 冻结弹 + 碎冰溅射 |
| 激光 + 电弧 | 电弧激光 | 光束链式传导 |

**手机 UI：** 选中 V 塔 → “升阶 / 融合”面板；相邻可融合塔高亮；点选预览；确认；不拖拽、不加建造栏卡片。
**为什么放 1.3–2.0：** 升阶/融合需要新资源、新 UI、新平衡；0.x 先不做，避免“系统太多，玩家看不懂”。

### 12.5 远期路线与验收

| 版本 | 内容 | 周期 | 成功标准 |
| --- | --- | --- | --- |
| **1.1.0** | 元素星域：3 群系、6 图、3 首领、连锁反应 | 4–6 周 | 每群系至少 2 种通关 build；环境伤害 ≤25% |
| **1.2.0** | 光环 + 天赋预设（方向验证） | 3–4 周 | 光环塔选取率 >30%；预设能形成不同打法 |
| **1.3.0** | 升阶：7 条具名路线 | 2–3 周 | 升阶使用率 >50%；不与 V 天赋叠加 |
| **2.0.0** | 6 个融合 + 3 章远征 + 全系统整合 | 6–8 周 | 无单一融合统治；手机端可读 |

**风险：**

- 元素格 + 反应 + 光环 + 天赋 + 融合叠加 → 认知/性能过载；每版只加一层，先做 1.1 再 1.2、1.3。
- 天赋是“二选一”不是“技能树”：每层只给 2 个选项，避免 7 塔 × 多层的选择爆炸。
- 融合占 2 塔位，可能让玩家觉得“少两座塔”；用强度/射程补偿，并允许回收。
- 新地图成本高；先做 3 群系各 2 图，不铺 10 图。
- 元素格必须可读；320×568 下用纹理/边界，不只靠颜色。

## 结语

**先让玩家在第一次超载时说出“卧槽”，再考虑怎么让他玩第 100 局。**

0.14 只验证一件事：**经典关 + 等离子 + 超载，按下去爽不爽。**  
爽了，再开超载模式（短局刷分）和无限模式（长局 build）；不爽，就回到超载和反应本身继续调，而不是继续加关卡。
