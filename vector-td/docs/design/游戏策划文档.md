## 1. 游戏概览

### 1.1 一句话定位

在一张 **9 × 16** 的深空网格上，用七种攻击塔、灯塔、偏折壁垒和三大伤害通道，守住底部星域核心，清剿十片星区。

### 1.2 基本信息

| 项目 | 基准 |
| --- | --- |
| 游戏名 | VECTOR // 矢界防线 |
| 类型 | 竖版深空塔防 / 路径改写 / 轻量局外成长 |
| 平台 | 移动优先的纯静态 Web（Canvas 2D + 原生 JavaScript） |
| 网格 | 9 列 × 16 行 |
| 当前基准内容 | 10 个星区，每关 14–20 波；7 攻击塔 + 灯塔 + 壁垒 |
| 单关时长 | 约 5–8 分钟（1×，含部署与整备） |
| 战役时长 | 约 60–75 分钟（首通，含重试） |
| 局外成长 | 7 条 × 5 阶全局技能，金币永久升级 |
| 存档 | `localStorage` 键 `vector_geotd_save_v1` |

> 当前基准**只包含经典战役**。超载模式、无限模式、元素星域、光环、天赋预设、升阶、融合均为扩容提案，不属于 0.14.5 基线。

### 1.3 核心体验

- **改写航线**：塔与壁垒都占格，会迫使敌人重新寻路；玩家用建筑“画”出更长的路线与交叉火力。
- **克制决策**：敌人拥有护盾、韧性、隐匿、物免、魔免等特性；单一塔种会被针对，必须混编动能 / 能量 / 低温。
- **五阶进化**：同一座塔从 I 到 V 级不仅数值提升，塔体轮廓、光环、卫星、弹道与命中特效都会逐级变化。
- **短局可读**：全屏 Canvas、透明 HUD、常驻建造栏；进入关卡默认暂停，暂停不遮挡战场，倒计时自动发兵。
- **长期成长**：金币只用于七条全局技能线；技能在下一局生效，帮助玩家跨过后期星区的数值与特性门槛。

### 1.4 设计支柱

1. **路线优先于数值**：好的建筑布局比单纯堆塔更有效。
2. **克制优先于堆叠**：先看敌情特性，再决定塔种与伤害通道。
3. **视觉优先于文字**：塔的等级、敌人的特性必须在战场上能一眼分辨。
4. **失败可解释**：玩家能说出“这波为什么漏”，而不是只看到核心归零。
5. **调试可复现**：开发期能直达任意关卡、任意加点、任意生成敌群。

### 1.5 目标玩家与单局节奏

- 喜欢塔防、路径规划、轻 Rogue-lite 成长的移动端玩家。
- 单局结构：进入关卡暂停 → 点击播放开始 25 秒初始部署 → 12 秒波间整备 → 自动发兵 → 清空后进入下一波。
- 失败成本低：可重开、可倍速、可随时暂停；局外成长永久保留。
- 操作负担低：主要交互是“选塔 → 点格 → 升级 / 回收”，没有需要持续点击的技能。

## 2. 核心循环

### 2.1 局内循环

```text
选择星区
  ↓
准备阶段（25s / 12s）：建造、升级、回收、用壁垒改写航线
  ↓
自动发兵（可点击倒计时提前发兵）
  ↓
交战：索敌 → 伤害类型结算 → 护盾/抗性/韧性 → 击杀获得晶元
  ↓
清空波次 → 修复（纳米修复）→ 下一波
  ↓
守住核心 → 结算星级与金币 → 解锁下一星区
```

### 2.2 局外循环

```text
通关 / 重复通关 / 星级奖励 → 金币
  ↓
七条全局技能线（核心装甲 / 晶体共振 / 武器超频 / 建造协议 / 静滞场域 / 纳米修复 / 初始电容）
  ↓
下一局生效 → 挑战更高星区
```

### 2.3 两种资源

| 资源 | 获取 | 使用 | 是否跨局 |
| --- | --- | --- | --- |
| 晶元 | 击杀敌人、关卡起始晶元 | 建造、升级、壁垒 | 否，每局重置 |
| 金币 | 首次 / 重复通关星区、星级奖励 | 七条全局技能线 | 是，永久保存 |

设计意图：

- 晶元只影响单局节奏，避免“越玩越富”导致局内无压力。
- 金币只影响长期成长，不直接变成局内战力，避免付费式滚雪球。
- 经济收束的目标是让玩家在“多建一座低阶塔”与“升级一座高阶塔”之间做取舍。

## 3. 战斗基础

### 3.1 网格与航线

- 网格为 9 列 × 16 行；敌人从顶部裂口进入，沿 BFS 流场走向底部核心。
- 塔和壁垒都会阻挡敌人，迫使重新寻路。
- 系统禁止封死所有“裂口 → 核心”的通路；也禁止把场上敌人困死。
- 偏折壁垒不攻击、不占塔位，只用于拉长航线、制造转角与交叉火力。
- 路径渲染为低亮度发光通道 + 低频流动粒子 + 每三格一个方向箭头；障碍物保持暗色实心岩体、无发光。

### 3.2 建造、升级与回收

- 每局最多同时存在 **12 座防御塔**（含灯塔）；偏折壁垒不占火力单元。
- 建造：选中建造栏卡片 → 点击高亮星格；右键 / 空白处取消。
- 升级：点击已建塔 → 升级；攻击塔最高 V 级，灯塔可升阶一次（125 晶元，侦测半径 3.5 → 4.5）。
- 回收：
  - 准备阶段或暂停期间最后放下的一座**未升级设施（防御塔或壁垒）**可全额撤销；
  - 其他情况返还 60% 投入。
- 升级成本：II–V 级分别乘以 `1.0 / 1.3 / 2.0 / 3.2` 的阶梯系数（`UPGRADE_COST_MULTIPLIERS`），后期升级明显更贵。
- 暂停期间仍可建造、升级、回收，方便长考；暂停中刚部署的未升级设施可按原价撤销。
- 选中建造卡片或设施时，详情面板接管建造栏所在的底部条带（同宽、同底、同高），不向战场网格延伸。

### 3.3 波次与敌情

- 每局开始有 **25 秒**初始部署时间；进入关卡时默认暂停，点击播放后才开始倒计时。
- 每波清空后有 **12 秒**整备时间；剩余 3 秒发出警报；归零自动发兵。
- 点击顶部倒计时卡可立即发兵；暂停时点击该卡会同时恢复作战并立即发兵。
- 交战期间点击波次卡不再弹出敌情；敌情只在暂停时通过 HUD 中间的「敌情」图标展开。
- 支持 ×1 / ×2 / ×3 倍速；暂停冻结倒计时（`P` / `Esc` / `Space`）。
- 每关进入默认暂停；暂停只冻结战场，不改变 HUD 高度、战场尺寸或网格位置。

## 4. 防御体系

### 4.1 防御单位总览

| 单位 | 伤害 | 建造 | I 级 DPS | V 级累计投入 | V 级基础 DPS | 核心定位 |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| 棱镜箭塔 PRISM | 动能 | 55 | 20.7 | 1,120 | 197.0 单体 / 293.9 双目标 | 廉价远程基线、魔免 |
| 矢量机炮 GATLING | 动能 | 70 | 30.0 | 1,380 | 315.4 | 近距离持续单体、魔免 |
| 引力重炮 CANNON | 动能 | 90 | 16.0 | 1,736 | 140.0（范围） | 群伤、分裂体、高生命 |
| 相干激光 LASER | 能量 | 105 | 18.0 | 1,991 | 122.0（满升温 329.4） | 护盾 / 物免 |
| 谐振震荡 SHOCK | 能量 | 95 | 9.3 | 1,827 | 83.8（范围） | 近域群伤、击退、护盾 |
| 熵减冻结 FROST | 低温 | 80 | 4.5 | 1,518 | 40.0（多目标） | 减速控制、高速单位 |
| 链式电弧 TESLA | 能量 | 120 | 13.8 | 2,325 | 143.5（五链 511.7） | 连锁、护盾、物免 |
| 灯塔 BEACON | 支援 | 60 | — | 185 | — | 揭示 3.5（升阶 4.5）格内隐匿；占 1 塔位 |

> DPS 为单体基础值；重炮、震荡、冻结、电弧的实际总伤害受范围 / 目标数 / 链数影响。棱镜 IV 起可同时锁定两个目标：IV 主箭 40、副箭 20；V 主箭 65、副箭 32。完整逐级表见[单位图鉴](单位图鉴.md)。

设计意图：

- 三种动能塔共享“对护盾低效、对魔免有效”的通道特征，但分别覆盖远程基线、近战持续、范围爆发。
- 三种能量塔共享“破盾、被魔免克制”的特征，但分别覆盖单体、近域、连锁。
- 冻结塔伤害最低，但提供不可替代的减速；高韧性单位让控制收益骤降，迫使玩家换纯伤害塔。
- 灯塔是唯一的反隐手段，不攻击、占 1 个塔位；可花费 125 晶元升阶为「远侦灯塔」（半径 3.5 → 4.5）。它的价值取决于覆盖位置，其次才是等级。

### 4.2 伤害类型与护盾

| 伤害类型 | 塔 | 对护盾倍率 | 设计定位 |
| --- | --- | ---: | --- |
| 动能 KINETIC | 棱镜、机炮、重炮 | ×0.45 | 实体弹道；破盾差，但能穿透魔免力场 |
| 能量 ENERGY | 激光、震荡、电弧 | ×1.90 | 高能光束；破盾快，但被魔免 / 能抗削弱 |
| 低温 CRYO | 冻结 | ×0.90 | 直接伤害低，主要提供减速 |

护盾规则：

- 护盾是独立于生命值的第二条耐久条，先于生命值被扣除。
- 护盾伤害按上表倍率结算；护盾被击穿后，溢出伤害按倍率折算回生命值。
- 护盾不享受敌人的抗性；抗性只作用于生命值伤害。
- 护盾破裂时播放独立特效、音效和“护盾破裂”浮字。

### 4.3 敌人特性

| 特性 | 效果 | 克制方式 |
| --- | --- | --- |
| 护盾 | 独立护盾条；能量 ×1.9、动能 ×0.45、低温 ×0.9 | 激光 / 电弧 / 震荡 |
| 物免 | 动能伤害按单位减免（重棱 40%、铁壁 65%） | 能量 / 低温 |
| 魔免 | 能量与低温伤害减免 75% | 棱镜 / 机炮 / 重炮 |
| 能抗 | 能量伤害降低 40% | 动能 / 低温 |
| 能量易伤 | 受到的能量伤害 +20% | 激光 / 电弧 / 震荡 |
| 韧性 | 按类型独立减免减速与击退（铁壁 80%、终焉 100%）；被控命中累积对应韧性 +12%/次，上限 80% | 纯伤害塔；控制收益大幅缩水 |
| 隐匿 | 常规索敌无法锁定；仅灯塔范围内可被命中 | 灯塔 |
| 分裂 | 死亡时分裂为两个高速残片 | 重炮 / 震荡 / 电弧等范围火力 |
| 终焉 | 最终首领；护盾 + 韧性 100% | 动能破甲 + 能量破盾的混编火力 |

控制补充规则：

- 减速与击退分轨道结算，互不抵消；控制命中会累积对应轨道的韧性。
- 韧性 80% 时，54% 的减速只剩约 10.8%；韧性 100% 完全免疫。
- 震荡塔附带击退：0.1 秒快速位移，最大 0.6 格；击退有 0.9 秒免疫窗，防止多塔无限顶停。
- 核心周围 1.6 格为击退免疫区，最后一段航道不能被推出。
- 控制可以削减但非绝对免疫；100% 免疫为终焉专属。

### 4.5 灯塔与反隐

- 灯塔：60 晶元建造、125 晶元升阶，侦测半径 3.5 → 4.5；不攻击、不可再升级、占用 1 个塔位。
- 灯塔半径内的隐匿单位会被揭示，所有防御塔都能锁定并攻击；离开范围会重新隐匿。
- 其他防御塔不再自带反隐；多裂口地图可能需要多座灯塔覆盖不同航线。

## 5. 成长与难度

### 5.1 星级、金币与技能

- 失败条件：核心完整度归零。
- 星级：
  - 完整度 ≥ 80%：3 星；
  - 完整度 ≥ 40%：2 星；
  - 其余通关：1 星。
- 首次肃清获得完整金币 + 星级奖励；重复通关获得 30% 基础金币 + 星级提升奖励。
- 七条全局技能线，每条五阶，使用金币永久升级，下一局生效；技能矩阵支持全额重置。
- 技能的具体数值、成本与收益见[数值策划](数值策划.md)第 5.3 节。

### 5.2 难度目标

- **骨灰级**：不刷金币、不点修复，L1–L10 一命无伤；靠资源利用率、站位、通道与时机，而不是数值溢出。
- **普通级**：首通 + 1–2 轮适度刷金币，L1–L10 正常通关；允许掉血、漏怪、1 星过 L10。
- **无脑级**：只铺棱镜 + 必要灯塔，即使满技能也无法完成战役；L10 必须失败。
- 任何单塔/单流派都不能平推全战役；每个特性至少 2 条解法（隐匿由灯塔承担）。

> 三档矩阵与未通过项见[验证记录_三档玩家](验证记录_三档玩家.md)；完整口径见[数值策划](数值策划.md)第 7 节，关卡逐个目标见[关卡策划](关卡策划.md)第 7 节。

## 6. 视觉与反馈基准

### 6.1 视觉语言

- 全屏 Canvas；深空黑底、霓虹青 / 品红 / 金色线条；所有图形、塔、敌人、特效、星空均由 Canvas / CSS 程序化绘制。
- 塔的 I–V 级必须有肉眼可分辨的轮廓 / 光环 / 卫星 / 弹道差异，不能只靠星星数量。
- 路径是低亮度发光通道 + 低频流动粒子 + 每三格一个方向箭头；出生门为危险色。
- 障碍物（小行星）必须是清晰可辨的实心岩体：实色填充 + 明确轮廓 + 裂纹纹理，亮度明显高于星空背景（目标对比 ≥4×），但不得使用发光/阴影。

### 6.2 敌人特性视觉

- **护盾**：青蓝色旋转六边形泡 + 独立护盾条；受击闪白。
- **韧性**：橙色四角括号；控制被完全吸收时括号闪亮。
- **隐匿**：半透明本体 + 虚线折射环 + 扫描线；进入灯塔范围后改为金色锁定环与常亮本体。
- **物免 / 魔免 / 能抗 / 能量易伤**：本体上方的菱形徽章（物 / 魔 / 能 / 弱）。
- **分裂**：分裂时环 + 粒子爆发，残片使用更小的三角体。
- **首领**：双层轨道、护盾泡、独立名称、护盾条 + HP 条。

设计原则：颜色只是辅助，形状和徽章才是主识别；色盲玩家也能通过轮廓与文字分辨。

### 6.3 UI 信息层级

- 顶部 HUD：暂停键 + 晶元居左；波次 / 倒计时、倍速、音量居右；关卡标题不常驻 HUD。
- 波次预览：敌人图标 + 数量 + 特性徽章；暂停时通过「敌情」图标展开当前波次敌情；浮层不改变战场尺寸。
- 暂停图标：`重开 / 星图 / 敌情 / 全屏` 四个纯图标；暂停与恢复时左右两组位置、HUD 高度和战场网格都不变化。
- 续战：暂停后返回星图或主界面，当前局保留在内存中；星图与首页显示「继续作战」。
- 新特性简报：首次进入引入新特性的星区时弹出特性说明与克制建议，写入 `seenTraits`，已读不重复。
- 建造栏：9 个栏位（7 攻击塔 + 灯塔 + 壁垒）、容量、最低费用、免费建造状态。
- 设施详情：伤害类型、特性标签、克制提示、当前 / 下一级数值、升级 / 回收；选中时接管建造栏所在的底部条带。
- 结算：星级、完整度、击杀、用时、金币；调试模式明确标注“不记录”。

### 6.4 移动端与可访问性

- 必须检查 320×568、390×667、390×844；不得横向溢出。
- 建造栏 9 个名称与费用不得被裁切；触控目标 ≥44px。
- 手机进入关卡默认请求 Fullscreen；`#app` 高度使用 `--app-height`（visualViewport）兜底。
- 全屏/独立应用模式下取消 560px 宽度上限（桌面全屏上限 720px），战场不得保留 1px 边缝。
- Fullscreen 状态同步到 `body.is-immersive` 与按钮 `aria-pressed` / `aria-label`；进入时尝试竖屏锁定与 Wake Lock，离开/暂停/切后台时释放。
- iPhone Safari 不支持网页 Fullscreen API 时，提示「分享 → 添加到主屏幕」，以 `display: fullscreen` 的 PWA 清单提供全屏启动。

## 7. 平台与技术基线

- 纯静态 HTML + CSS + 原生 JavaScript；无框架、无构建步骤、无外部 CDN / 图片 / 字体 / 音频。
- Canvas 2D 程序化绘制；Web Audio 程序化音效。
- 使用相对路径，保证部署在 `/games/vector-td/` 子路径下可运行。
- `localStorage` 键：`vector_geotd_save_v1`；调试状态键：`vector_geotd_debug_v1`；调试金币键：`vector_geotd_debug_gold_v1`。
- 目标：中端手机 60fps；同屏敌人上限由关卡密度与性能测试共同约束。
- 不依赖后端；所有进度、星级、金币与技能在本地保存。

## 8. 调试与验收入口

调试模式面向开发与验收，不属于正常玩法：

- 默认在 `localhost` / `127.0.0.1` / `file://` 开启；`?debug=1` / `?debug=0` 或 `Ctrl + Shift + D` 强制切换。
- 首页顶部 `DEBUG`，游戏内 HUD 的 `DBG` 打开面板。
- 能力：直达任意关卡、10000 金币（每个浏览器档案一次）、全技能 5 阶 / 重置、局内 +500 晶元、修复核心、攻击塔 5 级、准备时间 30 秒、无敌核心、免费建造 / 升级、立即发兵、清空敌军、直接胜负、生成测试敌群。
- 调试战斗不写入正式进度、星级或金币。

完整调试 API 与命令见 [`src/app.js`](../../src/app.js) 末尾与 [游戏 README](../../README.md)。

2. **关卡与数值分离**：关卡内容写 `关卡策划.md`，公式与数值写 `数值策划.md`；本文件只保留系统级摘要与链接。

5. **过期内容处理**：历史版本变更不留在总案；需要留档时写入对应 baseline 文档的“完成记录”或附录。
