## 0. 这次的标准是什么

“平铺箭塔无伤到 W10”不是高标准，它只是**无脑通关方式**的底线。真正的标准是：

> **无脑平铺棱镜不应该是一套能通关的打法；它应该在 L4 之后被资源压力淘汰。**  
> **合格玩家要在“晶元、塔位、升级、通道、灯塔/壁垒、站位”之间做取舍，而不是“有钱就铺塔”。**

### 0.1 两个测试对象

**A. 无脑平铺棱镜（必须失败）**

- **只建棱镜 + 必要的灯塔**；
- 不建其他攻击塔、不建壁垒；
- 隐匿关必须造灯塔；灯塔占 1 个塔位，所以是 **11 棱镜 + 1 灯塔**，不是 12 棱镜；
- 没有隐匿的关不造灯塔；
- 站位贪心（靠近路径即可），不根据波次换目标；
- 有钱就铺新塔，升级随缘；
- 无技能 / 首通预算各跑一次。

**目标结果：**

- L1–L3：可以通关（教学关），但不能“每波 0 损 0 决策”；
- L4–L6：最迟 W10 前失败，或核心 <40%；
- L7–L10：W6 前明显崩，不能靠数量堆过去；
- 任何关卡：不允许“11 棱镜 + 1 灯塔”成为稳定解。

**B. 资源压榨型混合 build（应该能过）**

- 首通预算 3–4 条技能线；
- 至少 2 种伤害通道；
- 隐匿关有灯塔；
- 多裂口关有 1–2 段壁垒/合理站位；
- 允许 1–2 次漏怪/重开，不要求零漏；
- L10 1 星也算过。

### 0.2 混合 build 试玩验证（2026-10-30）

**方法：** Chrome 390×844，3× 速度，正常建造；L4 起手 3 座 I 级棱镜（位置 3,2 / 5,2 / 4,5），W1 后补激光，随后按“先补塔、再升级”的混合策略。

| 波次 | 完整度 | 塔数 | 结果 |
| ---: | ---: | ---: | --- |
| W1 | 100 | 3 | 0 损 |
| W2 | 100 | 4 | 0 损 |
| W3 | 86 | 4 | -14 |
| W4 | 38 | 5 | -48 |
| W5 | 0 | 5 | 失败 |

**结论：**

1. **前 2 波确实偏松**：3 座棱镜 + 1 座激光即可 0 损，支持和之前“前面 wave 压力低”的体感。
2. **L4 的墙不在 W10，而在 W3–W5**：第一次护盾、护盾+分裂、物免+能抗连续三波，混合 build 在 5 塔时就被打穿。
3. **纯棱镜 12 塔反而能过 W1–W15（无技能 bot）**：说明当前问题不是“绝对难度”，而是**资源曲线断层**——正常首通开局的 3–5 塔撑不住 W3–W5，而满编 12 塔的运营又能把前 15 波打成 0 损。
4. **v2 的“L4 W10 门”不够准确**：L4 的资源检查点应前移到 W3/W5；W10 只是第二道门。
5. **v2 的“混合 build 应该能过”尚未被验证**：以当前 L4 起始 185 晶元，正常混合开局会死在 W5；需要先调整 L4 起始晶元/前 3 波密度，或明确“首通预算下允许重开/换 build”。

> 因此，v2 的方向（资源压榨）成立，但具体检查点要按实测前移：**L4 先修 W3–W5，而不是只盯 W10。**

### 0.3 什么叫“资源利用率被压榨”

不是“钱少到买不起”，而是：

- 钱刚好不够“所有塔都升满”，必须选 2–4 座关键塔；
- 塔位刚好不够“覆盖所有线 + 灯塔 + 墙”，必须做取舍；
- 低阶铺塔的 DPS/晶元低于“少而精”的升级路线；
- 每一波都在问：**你现在把钱花在哪？**

## 1. 资源压力模型

| 资源 | 压力来源 | 无脑棱镜为什么亏 |
| --- | --- | --- |
| 晶元 | 检查波要求特定答案（能量/灯塔/墙） | 钱全变成低阶棱镜，遇到盾/隐匿/物抗没有余钱换 |
| 塔位（12） | 多裂口 + 灯塔 + 墙占位 | 11 棱镜 + 1 灯塔看似满编，实际没有破盾/控场 |
| 升级 | 高有效 HP/物抗波 | 低阶棱镜单发低，铺 11 座不如升 3 座 |
| 伤害通道 | 盾/物免/魔免/隐匿/分裂 | 单动能通道被盾/物抗吃死 |
| 灯塔 | 隐匿波 | 不建灯塔，幽影完全打不到 |
| 壁垒/站位 | 多裂口、短路径 | 不拉线，输出时间不够；铺塔也打不满 |
| 时间 | 20s 初始 / 10s 波间 | 无脑铺塔来不及升级/换塔，检查波直接崩 |

### 1.1 资源效率指标（验收用）

| 指标 | 目标 | 说明 |
| --- | --- | --- |
| W10 晶元余额 / 总收入 | 10–25% | 太高=经济太松；太低=没有选择空间 |
| W10 塔位使用 | 8–11 / 12 | 11 棱镜 + 1 灯塔 = 反例 |
| 升级投入 / 建造投入 | ≥60% by W10 | 逼玩家“少而精”，不是铺满 |
| 伤害通道数 | W6 前 ≥2；L9 起 ≥3 | 单通道不应该是稳定解 |
| 灯塔 | 首次隐匿波前建成 | 没有灯塔 = 直接漏 |
| 壁垒 | 多裂口关 ≥1 段 | 不拉线 = 输出时间不足 |
| 漏怪 | 每关 0–2 | 不要求零漏，但不能靠漏怪过关 |

## 2. 波次角色

每一波必须有一个角色，不能“为了凑波数”：

| 角色 | 作用 | 无脑棱镜结果 |
| --- | --- | --- |
| 教学 | 教一个新单位/操作 | 可 0 损 |
| 呼吸 | 让玩家升级/补塔 | 可 0 损，但不能连续 3 波 |
| 资源检查 | 必须把钱花在正确位置 | 掉血/漏/崩 |
| 尖刺 | 单波高压，检验 build | 掉血/漏 |
| 混合考试 | 两种以上克制同时出现 | 崩/漏 |
| 终波 | 收尾，不引入新机制 | 掉血/漏 |

**规则：**

- 不允许连续 3 波“呼吸/0 损”；
- 每关 W3/W6/W10 至少各有一个资源检查；
- L4 起，资源检查必须让无脑棱镜付出代价，不能只“看起来有盾”。

## 5. 资源压榨的实现顺序

### Phase A：先证明“无脑棱镜会死”

1. 做一个无脑测试档：只建棱镜 + 必要灯塔，不建墙/其他塔；纯棱镜无灯塔只作为极端下限样本；
2. 跑 L4–L10，记录第一次崩的波次；
3. 如果 L4 仍能过，先改 L4 W6/W10，不改 L1–L3；
4. 如果 L5/L7 仍能过，改该关 W2/W10 的“硬克制”数量/gap。

### Phase B：再证明“认真玩能过”

1. 首通预算 3–4 条线；
2. 混合 2–3 通道 + 灯塔 + 1–2 段墙；
3. 目标：L10 1 星通过，允许 1–2 漏；
4. 如果认真玩也过不了，回退检查波数量，不降低标准。

### Phase C：最后调经济

- 如果无脑棱镜死于“没钱”，而不是“没做对”，说明经济太紧；
- 如果认真玩晶元余额 >30%，说明经济太松；
- 只调首通金币/技能成本，不靠全局加血。

## 6. 验收

### 6.1 无脑棱镜

- [ ] L1–L3 可通关，但 W10 不再 0 损 0 决策；
- [ ] L4 最迟 W10 失败，或核心 <40%；
- [ ] L7 最迟 W6 明显崩；
- [ ] L10 W1–W3 至少一波漏；
- [ ] 11 棱镜 + 1 灯塔不是任何一关的稳定解。

### 6.2 认真混合

- [ ] 首通预算 3–4 条线；
- [ ] W6 前至少 2 通道；
- [ ] 隐匿关首次隐匿波前有灯塔；
- [ ] 多裂口关至少 1 段墙/合理站位；
- [ ] L10 1 星通过，允许 1–2 漏；
- [ ] 不要求零漏、不要求满技能、不要求重复刷。

### 6.3 资源指标

- [ ] W10 晶元余额/总收入 10–25%；
- [ ] W10 塔位 8–11/12；
- [ ] 升级投入/建造投入 ≥60%；
- [ ] 无脑棱镜的升级投入明显低于混合 build；
- [ ] 终波/Boss 体感不被前 19 波改动拉差。

## 7. 风险

| 风险 | 表现 | 对策 |
| --- | --- | --- |
| 把“无脑棱镜会死”做成“所有人都得死” | 认真混合也过不了 | 检查波只惩罚单通道；混合有明确答案；首通预算复跑 |
| L4 第一道门太重 | 新手卡 L4 | 先只改 W6/W10，W3 保持教学；允许 1–2 漏 |
| 经济太紧 | 无脑棱镜死于没钱，而非没做对 | 提高首通金币/降低技能成本，不削检查波 |
| 经济太松 | 认真玩余额 >30%，仍可铺塔 | 降低首通金币或提高升级成本；优先看 W10 余额 |
| 波次太碎 | 每波都换类型，没有呼吸 | 保留 20–30% 呼吸波；每关 W11/W14 留缓冲 |

## 8. 结论

> **无脑平铺棱镜不是“高标准的失败”，而是“最低要求的不合格”。**  
> 本轮逐波设计的目标不是让所有波都变难，而是让 **资源利用效率** 成为通关条件：  
> 钱要花在破盾/反隐/升级/站位上；塔位要留给答案；低阶铺塔要被高有效 HP/物抗/隐匿波淘汰。

先做 Phase A：证明无脑棱镜在 L4–L10 会死；再 Phase B：证明认真混合能过；最后才调经济。
