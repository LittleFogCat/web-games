## 1. 评分口径

三档玩家与执行口径：

| 档位 | 人设 | 执行方式 |
| --- | --- | --- |
| 初级 | [初级游戏玩家](../persona/初级游戏玩家.md) | 单棱镜 + 必要灯塔、经济技能、无墙、合法经济 |
| 中级 | [中级游戏玩家](../persona/中级游戏玩家.md) | 混编 + 正常技能档、允许少量墙/灯塔、合法经济 |
| 高级 | [高级游戏玩家](../persona/高级游戏玩家.md) | ACE 混编 + 双灯塔 + 墙、无修复、无刷金币、核心掉血即失败 |

评分公式（0–1，越高越难）：

| 项 | 条件 | 加分 |
| --- | --- | --- |
| 初级门槛 | 初级失败 | +0.20 |
| 初级门槛 | 初级通关但漏怪 | +0.10 |
| 中级门槛 | 中级失败 | +0.40 |
| 中级门槛 | 中级通关但漏怪 | +0.25 |
| 中级门槛 | 中级无伤通关 | +0.05 |
| 高级门槛 | 高级无伤通关 | +0.35 |
| 容错 | 高级无伤但依赖 ≥6 段墙或双灯塔 | +0.05 |

分数按 1.00 封顶。

判定：
- L9 达标线 0.80：初级失败 + 中级漏怪通关 + 高级无伤 = 0.80。
- L10 达标线 0.90：初级失败 + 中级失败 + 高级无伤 = 0.95；若中级只是漏怪通关，则 0.85，不达标。

**关键设计结论**

- Boss 血量继续加会先打穿 ACE（4500/1.22 时 ACE 只剩 62%），所以最后用的是“漏 Boss 即致命”，而不是“Boss 更肉”。
