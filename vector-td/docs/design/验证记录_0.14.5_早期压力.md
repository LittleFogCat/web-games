# 0.14.5 早期压力验证记录

> 验证日期：2026-10-30  
> 目的：验证“多数关卡前中期波次压力过低”的体感，而不是只做静态推演  
> 方法：无头模拟（L1–L5，无技能，1 局）+ 浏览器实机（CDP，L1/L3 前 5–6 波）  
> 结论：**体感成立，但问题不是“所有波都简单”，而是“绝大多数波零压力，少数尖刺集中在中段/终波”**

---

## 1. 结论摘要

| 关卡 | 验证结果 | 关键现象 |
| ---: | --- | --- |
| L1 | 14/14 波 0 漏，100% 完整度 | 全程无压力；2 座 I 级棱镜即可清前 5 波 |
| L2 | 通关 63%，W2 漏 22、W3 漏 15，W4–W15 全 0 | 难度集中在开局 W2/W3，之后 12 波几乎无压力 |
| L3 | 16/16 波 0 漏，100% 完整度 | 无技能 12 塔全程零损失；前中期明显偏松 |
| L4 | W1–W15 全 0，W16 失败 | 前 15 波零压力，唯一难点是终波；符合“前面太松、最后突然难” |
| L5 | bot 构建失败（W1 即崩） | 该局不能作为难度证据；需单独手测 |

**判断：**

- L1 / L3 是“全程零压力”的典型；
- L4 是“前 15 波零压力、终波突然墙”的典型；
- L2 是“开局有尖刺、之后长时间无压力”的典型；
- 问题不是“整体数值太低”，而是**压力分布不均**：大部分波次 0 漏，少数波次集中难度。

## 2. 无头模拟数据

### 2.1 条件

- `tools/sim-headless.js`；
- `--skills none`（无全局技能）；
- `--runs 1`；
- L1–L5；
- bot 使用固定聚线/建造策略，最多 12 塔；不是人类最优，但能代表“有运营的玩家”。

### 2.2 L1：14 波全零

```text
L1 通关 14/14，完整度 100%，击杀 230，漏怪 0，塔 8
逐波损失：W1–W14 全部 0
```

**解读：** 无技能、8 塔即可零漏；前中期没有“差点漏”的波次。

### 2.3 L2：开局尖刺，之后 12 波全零

```text
L2 通关 15/15，完整度 63%，击杀 383，漏怪 9
W1 0
W2 22
W3 15
W4–W15 0
```

**解读：** W2/W3 是明显尖刺（分裂 + 双线），但之后 12 波完全没有压力；难度曲线是“开头一拳，后面放空”。

### 2.4 L3：16 波全零

```text
L3 通关 16/16，完整度 100%，击杀 454，漏怪 0，塔 12
逐波损失：W1–W16 全部 0
```

**解读：** 无技能 12 塔全程零漏；这是“前中期太松”的最强证据之一。

### 2.5 L4：前 15 波全零，终波失败

```text
L4 失败于 W16，完整度 0，漏怪 12（shard×6、splitter×1、brute×5）
W1–W15 全部 0
W16 失败
```

**解读：** 前 15 波零压力；唯一难点是终波。和你说的“最终波难度合适或稍高、前面太低”一致。

### 2.6 L5：无效样本

```text
L5 失败于 W1，完整度 0，漏怪 17
BUILD: 2 beacon + 1 prism + 1 wall
```

**解读：** bot 的建造策略在 L5 失效（灯塔过多、火力不足），这局不能说明 L5 难度，需手测。

## 3. 浏览器实机验证

### 3.1 条件

- 390×844，Chrome headless，CDP；
- 进入关卡默认暂停；脚本放置 2–4 座 I 级棱镜，3× 速度；
- 不手动使用技能/调试数值；只做正常建造/升级。

### 3.2 L1：2 塔清前 5 波，0 损

```text
起手：2 座 I 级棱镜，晶元 30
W1：2.9s（3×），完整度 100，晶元 54
W2：4.2s，完整度 100
W3：3.4s，完整度 100
W4：7.1s，完整度 100，塔 3
W5：5.0s，完整度 100，塔 4
```

**解读：** 2 座 I 级棱镜即可清 W1–W3；W4 加重棱后仍 0 损；前 5 波没有紧张感。按 1× 估算，单波约 9–21 秒，其中大量时间在等怪/清残。

### 3.3 L3：4 塔前 3 波 0 损，W4 开始掉血

```text
起手：3 座 I 级棱镜，晶元 15
W1：5.5s，完整度 100
W2：4.2s，完整度 100，塔 4
W3：6.1s，完整度 100
W4：15.9s，完整度 67（-33）
W5：15.6s，完整度 46（-21）
```

**解读：** 前 3 波依然零压力；W4 的相位/分裂组合才开始有压力。说明“早期太松”至少覆盖前 3 波，之后才进入正常难度。

> 实机测试中首次出现“能抗”时会弹新特性简报并暂停；脚本已关闭简报并恢复。上面的 L3 数据是关闭简报后的结果。

## 4. 这些数据说明了什么

1. **不是“所有波都太简单”**：L2 W2/W3、L3 W4、L4 W16 都有压力。
2. **是“大多数波次零压力”**：L1 14/14、L3 16/16、L4 前 15/16 都是 0 漏。
3. **难度分布是“哑铃形”**：少数尖刺 + 大量空波；不是平滑上升。
4. **L4 是最典型的“前松后紧”**：前 15 波零压力，终波直接失败；终波本身可能合理，但前面的 15 波没有承担教学/递进作用。
5. **L2 是反例**：开局 W2/W3 有尖刺，后面反而空；说明“早期加难度”不能全局一刀切，要先看每关的尖刺位置。

---

## 5. 对调整方案的修正建议

| 关卡 | 基于验证的调整 |
| ---: | --- |
| L1 | 前 5 波必须加密度/缩 gap；至少让“只建 1 塔”有漏怪风险；不要动终波 |
| L2 | **不要继续加 W2/W3**；先平滑这两个尖刺，再把 W4–W15 的零压力波加密度/换组合 |
| L3 | 前 3 波加密度；W4 之后已经有一定压力，先观察，不要整关一起加 |
| L4 | 前 15 波必须加压力；终波保持；不要用加盾卫数量来解决前期 |
| L5 | 需要单独手测；当前 bot 样本无效，不能据此加/减 |
| L10 | 本轮未验证；前 19 波需单独跑，W20/Boss 不动 |

**原则：**

- 先修“零压力波”，不要修“已有尖刺的波”；
- 每关先找“0 漏的连续段”，只动这段；
- 一次只改 1–2 波，复跑后再继续；
- 终波/Boss 保持，除非验证证明终波也偏松。

---

## 6. 验证局限

- 无头 bot 会聚线、建 12 塔、使用固定策略；它不是人类，可能高估“简单”；
- 浏览器实机只跑了 L1/L3 前 5–6 波，未覆盖全部关卡；
- L5 bot 样本无效；L10 未验证；
- 3× 速度会放大“清屏快”的体感，但 0 漏/0 损的结论不受速度影响；
- 没有真实玩家操作数据；最终以你的手测为准。
