## 2. 判定口径

- **骨灰级**：`win && minHpPct === 100`；不点修复，只花首通 + 满星奖励；核心第一次掉血即失败；每档 3 个种子，至少 2/3 无伤。
- **普通级**：`win`；首通 + 1–2 轮重复通关，允许 1–2 阶修复；允许掉血/漏怪；每档 3 个种子，至少 2/3 通关。
- **无脑**：只建棱镜 + 必要灯塔，满技能（七线全 5 阶）；按关卡顺序推进，第一关失败即阻断战役；每档 3 个种子，必须 0/3 通关才算阻断。
- 所有局不使用调试资源；种子固定；bot 策略见 `tools/balance-gate.js` 的 `ARCHETYPES`。

## 4. 关键发现

### 4.1 修复规则是“无脑躺赢”的最大来源

旧规则“每波结束修复 6–30 点”让无脑 build 可以接受 20–40 只漏怪，再用修复回血。改为“本波有漏怪则不触发”后：

- 无脑 L10 从 47% 通关变为失败；
- 无脑 L9 从 60% 通关变为 W6–W9 失败；
- 普通/骨灰的干净波次仍能吃到修复，未被误伤。

**结论：** 机制保留，规则改为奖励干净波次；这是结构性修正，不是数值补丁。

### 4.2 纯动能被铁壁物抗挡住，L9 成为无脑门

铁壁动能抗性 65%→75% 后：

- 无脑 L7/L8 开始大量漏铁壁，但仍能带伤通过；
- 无脑 L9 的三裂口 + 幽影 + 铁壁组合直接阻断；
- 普通靠 6 激光 + 5 棱镜混编，L7/L9 仍能过；
- 骨灰 L7–L9 能无伤。

**结论：** “物抗墙 + 隐匿覆盖”是最有效的无脑门；L9 保留，L7/L8 可继续加压。

### 4.3 Boss 是骨灰 L10 的最后一关

Boss 原 4,800 HP / 0.30 速度时，骨灰 3/3 都会在终波漏 Boss（掉到 62%）。先下调到 3,600 HP / 0.24；L9/L10 Loop 后再上调到 **4,000 HP / 2,000 盾 / 核心伤害 170**。

- 骨灰 L10 仍无伤；
- 普通 L10 会漏 1 只 Boss，且漏 Boss 直接清空核心，**普通不再通关**（Loop 后结果）；
- 无脑在 L9 已被阻断，不受影响。

**结论：** Boss 的调整从“给无伤留窗口”变为“Boss 漏怪即终局”；普通 L10 的门槛由“能通关”提高到“不能漏 Boss”。

### 4.4 普通 L6 是经济/建造顺序问题

L6 原来失败于 W8，根因不是“打不动”，而是：

- bot 只造 8 座攻击塔，晶元花在 2 座灯塔和低阶升级上；
- W8 的虚空织者（魔免）与折光盾卫（护盾）同时出现，需要更高等级的棱镜 + 激光。

修正：

- L6 起始晶元 235 → 280；
- 普通 bot 改为“先铺到 12 座再升级”，不再在 9 座时停手；
- W8 的相位/虚空/棱卫数量小幅下调。

结果：普通 L6 3/3 无伤通关。

## 6. 局限

1. 三档都是 bot 证据；bot 不会用冰冻/电弧/重炮的最优组合，不会 Boss 集火，不会手工迷宫。
2. 无脑 L7/L8 仍能带伤通过（64%/87%），只满足“无法完成战役”，不满足“L7+ 明显崩”。
3. 普通 L1–L6、L8–L9 多数无伤，普通档偏强；下一轮可考虑收紧普通技能预算或提高中盘压力。
4. 未做 1× 手测与三尺寸回归；按工作流，矩阵通过后必须补，才能写“已验证”。
