# 第一篇章-第一关（示例模板文档）

本文记录了第一关的通关策略。
本文仅作为通关示例，不代表真实第一关的通关策略。

## 一、无脑策略

模板注：无脑策略做为最基础平铺策略（例如，平铺箭塔，优先数量，搭配必需的灯塔），做为衡量关卡难度的基线。
模板注：除教学关外，无脑策略无法无伤通过后续关卡，且即使技能全满，也必然无法通过最终2个关卡。
模板注：极限策略为关卡设计的下限。如果无脑策略可以无伤通关，说明本关卡难度过低。

## 二、普通策略

模板注：普通策略是通过一定的搭配，可以走到比无脑策略更远。
模板注：普通策略在未刷金币的情况下，正常技能加点的情况下，无法通关最终关卡。在满技能的状态下，可以无伤通关除最终关外的关卡，可以有伤通关最终关卡。

## 三、极限策略

模板注：极限策略对资源的分配达到极致，通过精细的建造配比与资源投入策略，达到最大化的效率。
模板注：极限策略在未刷金币的情况下，正常技能加点的情况下，可以无伤通关最终关卡。
模板注：极限策略为关卡设计的上限。如果极限策略无法无伤通关，说明本关卡难度过高。
