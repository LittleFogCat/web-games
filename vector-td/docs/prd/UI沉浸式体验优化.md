# UI沉浸式体验优化

# 塔防游戏 UI 优化修改方案

## 1. Header 优化

目标：降低 HUD 的视觉存在感，增强战场的沉浸感。

- [x] 将 Header 的整体背景改为透明，移除顶部完整的实色背景区域。
- [x] 保留局部黑色渐变、轻微半透明遮罩或文字阴影，确保信息在复杂背景下仍然清晰可读。
- [x] 暂停按钮独立显示，避免与其他信息混为一体。
- [x] 关卡名称弱化显示，降低其视觉优先级。
- [x] 资源数量保留常驻显示，使用清晰的颜色区分不同资源。
- [x] 将波次信息与倒计时整合为紧凑的信息组，降低倒计时的视觉权重。
- [x] 弱化倍速、音量等辅助控件的视觉表现。
- [x] `DBG` 调试按钮仅在开发模式下显示，正式版本中隐藏。

## 2. 核心生命值优化

目标：减少常驻状态信息，让玩家通过战场反馈感知核心状态。

- [x] 移除 Header 中常驻显示的核心生命值数字。
- [x] 保留战场底部的核心实体、能量环和现有视觉特效。
- [x] 核心受到攻击时，触发短暂的红色闪光、能量环扰动等受击反馈。
- [x] 必要时增加屏幕边缘警告或受击方向提示，帮助玩家及时发现核心遭到攻击。
- [x] 核心生命值低于 30% 时，触发明显的受损警告。
- [x] 核心生命值低于 10% 时，进一步强化警告效果和音效。
- [x] 核心受击或进入危险状态时，可以短暂显示具体生命值。
- [x] 如有需要，允许玩家通过点击核心查看详细状态。

注：30% 和 10% 为建议初始阈值，应根据实际游戏节奏调整。如果核心生命值是玩家进行关键防御决策的重要依据，应确保玩家仍能及时获取准确数值。

## 3. 底部建造栏优化

目标：保留操作效率，同时减少 UI 对战场的遮挡。

- [x] 保留建造栏的背景和基本布局，不采用完全透明的设计。
- [x] 适当降低外围面板的背景不透明度和边框亮度。
- [x] 普通状态下弱化卡片背景和边框。
- [x] 选中、悬停、资源不足等状态下，再突出显示对应卡片。
- [x] 保留炮塔名称、图标、价格等必要信息，确保操作清晰。

## 4. 战场视觉优化

目标：让敌人、炮塔、核心和关键战斗事件成为视觉主体。

- [x] 适当减少青色路径上的重复箭头，避免视觉元素过于密集。
- [x] 可以使用低亮度的流动粒子表达路径方向。
- [x] 降低非关键路径特效的亮度，将视觉强调留给重要事件。
- [x] 提高敌人、核心受击效果和当前选中对象的视觉优先级。
- [x] 保持现有深色科幻风格，以青色作为主要战场色、橙色作为资源强调色，红色用于危险状态。

## 5. 实施优先级

### P0：优先完成
- [x] Header 背景透明化。
- [x] 移除核心生命值常驻数字。
- [x] 增加核心受击反馈和低血量警告。
- [x] 正式版本隐藏 `DBG` 按钮。

### P1：进一步优化
- [x] 调整 Header 的信息布局和视觉层级。
- [x] 弱化底部建造栏的背景与边框。
- [x] 减少路径上的重复箭头，优化战场视觉层次。

## 6. 验收标准

- Header 不再形成明显的横向实色分割区域。
- 战场背景能够自然延伸至屏幕顶部，整体视觉更加连贯。
- 正常战斗时不显示核心生命值常驻数字，但核心状态变化仍然容易感知。
- 核心受击和低血量状态具有清晰、及时且不过度干扰操作的反馈。
- 资源、波次、倒计时等必要信息仍然清晰可读。
- 建造栏保持良好的可操作性，不因透明化而降低文字和图标的辨识度。
- 整体保持深色科幻风格，减少 UI 面板感，突出战场本身。

## 7. 实施记录（v1.9.0）

已按 P0 / P1 全部落地：

- HUD 改为透明渐变浮层，去掉横向实色分割；暂停键独立为圆形控件，关卡名弱化，晶元常驻高亮，波次与倒计时合并为紧凑卡片，倍速/音量降级。
- 核心完整度不再常驻：受击时顶部短暂浮现数值并触发屏幕边缘红闪与受击方向提示；低于 30% 持续警示与红色边缘呼吸；低于 10% 强化闪动并播放更重的音效；点击战场底部的核心可查看完整度、百分比与累计漏怪。
- 建造栏保留背景和 9 栏布局，降低外围面板、普通卡片的透明度/边框亮度；选中、悬停、资源不足时高亮，名称/图标/价格始终可读。
- 路径箭头改为每三格一个，新增低亮度流动粒子；路径整体亮度下调，敌人、核心受击、当前选中设施的视觉优先级提高；`DBG` 继续只在调试模式显示。
- 本地回归：320×568 / 390×667 / 390×844 / 1280×900 无横向溢出；建造、右键取消、升级/回收、暂停/恢复、点击核心查看状态均通过；控制台无错误。
